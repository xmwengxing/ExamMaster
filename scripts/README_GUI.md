# 题库格式转换工具 - GUI版本使用指南

## 简介

题库格式转换工具GUI版本是一个带图形界面的Python应用程序，用于将Excel和Word格式的题库文件转换为系统支持的JSON格式。

## 功能特性

- ✅ 图形化界面，操作简单直观
- ✅ 支持Excel格式 (.xlsx, .xls)
- ✅ 支持Word格式 (.docx)
- ✅ 实时进度显示
- ✅ 详细的转换日志
- ✅ 智能错误提示和重试选项
- ✅ 自动生成JSON格式输出
- ✅ 一键打开输出文件

## 安装依赖

在使用工具之前，请确保安装了必要的Python库：

```bash
pip install openpyxl python-docx
```

### 依赖说明

- `openpyxl`: 用于解析Excel文件 (.xlsx, .xls)
- `python-docx`: 用于解析Word文件 (.docx)
- `tkinter`: Python内置的GUI库（通常已预装）

## 使用方法

### 1. 启动工具

在项目根目录下运行：

```bash
python scripts/convert-questions-gui.py
```

或者在Windows下双击运行：

```bash
题库转换脚本Python版.bat
```

### 2. 选择源文件

1. 点击"浏览..."按钮
2. 选择要转换的题库文件（Excel或Word格式）
3. 文件路径会自动显示在输入框中

### 3. 选择输出目录

1. 点击"输出目录"旁边的"浏览..."按钮
2. 选择转换后文件的保存位置
3. 默认为当前工作目录

### 4. 选择文件格式

根据源文件类型选择：
- Excel (.xlsx, .xls)
- Word (.docx)

工具会根据文件扩展名自动选择格式。

### 5. 开始转换

1. 点击"开始转换"按钮
2. 观察进度条和日志输出
3. 等待转换完成

### 6. 查看结果

转换完成后：
1. 会弹出成功提示框
2. 显示转换的题目数量和输出文件路径
3. 可以选择立即打开输出文件
4. 或点击"打开输出文件"按钮手动打开

## 文件格式要求

### Excel文件格式

Excel文件应包含以下列（顺序可以不同）：

| 列名 | 说明 | 必填 |
|------|------|------|
| 题型 | SINGLE/MULTIPLE/JUDGE/FILL/ESSAY | 否（默认单选） |
| 题目/题干 | 题目内容 | 是 |
| 选项 | 选项内容，用\|分隔 | 选择题必填 |
| 答案 | 正确答案 | 是 |
| 解析 | 题目解析 | 否 |

**示例：**

```
题型    题目                        选项                    答案    解析
单选    JavaScript是什么？          编程语言|数据库|操作系统  A      JavaScript是一种编程语言
判断    Python是编译型语言          -                       B      Python是解释型语言
```

### Word文件格式

Word文件应按以下格式组织：

```
1. 题目内容
A. 选项A
B. 选项B
C. 选项C
答案：A
解析：这是解析内容

2. 题目内容
...
```

转换后的JSON文件格式：

```json
{
  "metadata": {

    "totalQuestions": 100,

```

## 错误处理

### 常见错误及解决方法

#### 1. 文件不存在
**错误信息**: "文件不存在"
**解决方法**: 检查文件路径是否正确，文件是否被移动或删除

#### 2. 权限错误
**错误信息**: "权限错误"
**解决方法**: 
- 检查文件是否被其他程序（如Excel）打开
- 确保有读取文件的权限
- 尝试以管理员身份运行

#### 3. 数据验证错误
**错误信息**: "未能从文件中提取到任何题目"
**解决方法**:
- 检查文件格式是否正确
- 确保文件包含有效的题目数据
- 参考上面的文件格式要求

#### 4. 依赖库缺失
**错误信息**: "未安装openpyxl库"或"未安装python-docx库"
**解决方法**: 运行 `pip install openpyxl python-docx`

### 重试功能

当转换失败时，工具会显示详细的错误信息和修正建议，并提供重试选项。

## 日志查看

转换过程中的所有操作都会记录在日志区域，包括：
- 文件读取状态
- 解析进度
- 题目数量统计
- 错误详情

日志带有时间戳，便于追踪问题。

## 进度显示

工具提供实时进度显示：
- 进度条显示完成百分比
- 进度标签显示当前阶段和已处理题目数
- 状态栏显示整体状态

## 取消转换

如果需要中止转换：
1. 点击"取消"按钮
2. 确认取消操作
3. 转换会立即停止
