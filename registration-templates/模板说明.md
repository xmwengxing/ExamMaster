# 福建省职业技能等级认定申报表模板说明

## 模板文件
- 文件名: 福建省职业技能等级认定申报表.docx
- 位置: 报名管理/

## 占位符列表

### 基本信息
- `{{name}}` - 姓名
- `{{gender}}` - 性别
- `{{birth_date}}` - 出生年月（格式：YYYY.MM）
- `{{id_number}}` - 身份证号码
- `{{phone}}` - 联系电话

### 申报信息
- `{{occupation}}` - 申报认定职业
- `{{occupation_direction}}` - 工种/职业方向名称
- `{{apply_level}}` - 申报等级
- `{{work_years}}` - 从事本职业年限

### 工作单位
- `{{company}}` - 现工作单位
- `{{phone}}` - 电话

### 学历信息
- `{{highest_education}}` - 最高学历
- `{{highest_education_school}}` - 毕业院校
- `{{highest_education_major}}` - 最高学历专业
- `{{highest_education_graduation_date}}` - 毕业时间

### 证书信息
- `{{current_certificate}}` - 现已持何种职业证书
- `{{certificate_level}}` - 等级
- `{{certificate_code}}` - 证书编码
- `{{certificate_date}}` - 取得证书时间

### 学习经历（循环4次）
```
{{#education_history}}
  {{level}}           - 程度
  {{school}}          - 所在院校
  {{major}}           - 专业
  {{graduation_date}} - 毕业时间
{{/education_history}}
```

### 工作经历（循环3次）
```
{{#work_history}}
  {{period}}   - 何年至何年
  {{position}} - 从事何职业
  {{company}}  - 所在单位
  {{witness}}  - 证明人姓名、电话
{{/work_history}}
```

## 表格自动换行设置

为确保长文本能够正确显示，需要在Word中设置表格属性：

1. 选中整个表格
2. 右键 → 表格属性
3. 在"表格"选项卡中：
   - 首选宽度：100%
   - 对齐方式：居中
4. 在"单元格"选项卡中：
   - 垂直对齐方式：居中
   - 选项 → 勾选"自动换行"

## 测试方法

运行测试脚本验证模板：
```bash
node scripts/test-vocational-template.js
```

测试脚本会：
1. 加载模板文件
2. 填充测试数据（包含长文本）
3. 生成测试文档
4. 验证自动换行功能

## 注意事项

1. 占位符必须使用双花括号 `{{}}` 包裹
2. 循环部分使用 `{{#数组名}}` 开始，`{{/数组名}}` 结束
3. 表格单元格需要设置自动换行
4. 保存为 .docx 格式（不要使用 .doc）
