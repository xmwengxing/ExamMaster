# 部署快速指南

## 🚀 三步部署

### 第一步：检查服务器

双击运行：
```
check-server.bat
```

### 第二步：记录结果

打开 `服务器部署记录.md`，填写检查结果。

### 第三步：继续部署

根据检查结果：
- ✅ 如果都已安装 → 直接部署应用
- ⚠️ 如果缺少软件 → 先安装软件

## 📝 核心文件

| 文件 | 用途 |
|------|------|
| `check-server.bat` | 检查服务器环境 |
| `服务器部署记录.md` | **部署检查清单（重要）** |
| `当前状态.md` | 当前部署进度 |
| `部署说明.md` | 详细部署步骤 |
