# 部署注意事项

## 环境变量配置

项目现在使用两个独立的环境配置文件：

### 1. `.env` - 本地开发环境
- 用于本地 Docker 开发
- `DB_HOST=localhost`
- `DB_PORT=5434`
- `ALLOWED_ORIGINS` 包含 `http://localhost` 和 `http://localhost:5173`
- **不会被上传到服务器**

### 2. `.env.production` - 生产环境
- 用于服务器部署
- `DB_HOST=postgres`（Docker 容器名称）
- `DB_PORT=5432`（Docker 内部端口）
- `ALLOWED_ORIGINS=https://exammaster.zzzjl.com`
- **会被上传到服务器并重命名为 `.env`**

## 部署脚本说明

### quick-deploy.bat（推荐用于小改动）
✅ **安全**：不会修改服务器的 `.env` 文件
- 只更新代码文件（dist/, server.js, db.js, utils/）
- 重启 API 容器
- 适合日常代码更新

### deploy.bat（完整部署）
⚠️ **会覆盖服务器配置**：
- 上传 `.env.production` 并覆盖服务器的 `.env`
- 自动备份现有配置为 `.env.backup.时间戳`
- 重新构建 Docker 镜像
- 适合首次部署或重大更新

## 部署前检查清单

### 使用 quick-deploy.bat 前：
- [ ] 确认只修改了代码文件
- [ ] 运行 `npm run build` 成功
- [ ] 没有修改环境变量或依赖

### 使用 deploy.bat 前：
- [ ] 检查 `.env.production` 中的配置是否正确
- [ ] 确认数据库密码、JWT 密钥等敏感信息
- [ ] 确认 `ALLOWED_ORIGINS` 只包含生产域名
- [ ] 备份服务器数据（如有必要）

## 服务器环境变量管理

### 首次部署后，在服务器上：
```bash
# 连接到服务器
ssh root@47.104.173.139

# 进入项目目录
cd /www/wwwroot/exammaster.zzzjl.com

# 查看当前配置
cat .env

# 如需修改配置
nano .env

# 修改后重启服务
docker compose restart api
```

### 重要配置项（服务器特定）：
```bash
# 数据库配置（Docker 内部）
DB_HOST=postgres
DB_PORT=5432

# CORS 配置（生产域名）
ALLOWED_ORIGINS=https://exammaster.zzzjl.com

# 如需支持多个域名
ALLOWED_ORIGINS=https://exammaster.zzzjl.com,https://www.exammaster.zzzjl.com
```

## 常见问题

### Q: 部署后登录失败，提示 CORS 错误？
A: 检查服务器的 `.env` 文件中 `ALLOWED_ORIGINS` 是否包含正确的域名。

### Q: 如何恢复被覆盖的配置？
A: 服务器上有自动备份：
```bash
cd /www/wwwroot/exammaster.zzzjl.com
ls -la .env.backup.*
cp .env.backup.最新时间戳 .env
docker compose restart api
```

### Q: 本地开发时无法访问 http://localhost？
A: 确保本地 `.env` 文件中：
```bash
ALLOWED_ORIGINS=https://exammaster.zzzjl.com,http://localhost:5173,http://localhost
```

### Q: 如何只更新前端不影响后端？
A: 使用 `quick-deploy.bat`，它只更新代码文件。

## 安全建议

1. **不要提交 `.env` 文件到 Git**
   - 已在 `.gitignore` 中排除
   - 敏感信息不应进入版本控制

2. **定期更换密码**
   - 数据库密码
   - JWT 密钥
   - 建议每 90 天更换一次

3. **最小权限原则**
   - CORS 只允许必要的域名
   - 不要使用通配符 `*`

4. **备份配置**
   - 部署前备份服务器配置
   - 保存密码到安全的密码管理器
