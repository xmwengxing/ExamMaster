# 练习模式性能优化实施记录

## 优化时间
2026-01-28

## 问题描述
学员端在进入和退出练习模式（顺序练习、背题模式、自定义练习）时响应很慢，需要等待 3-5 秒才有反馈。

## 根本原因

### 1. 频繁的 API 调用
- 每次切换题目都会立即调用 `saveProgressImmediately`
- 用户快速切换时产生大量并发请求
- 网络延迟累积导致响应变慢

### 2. 退出时的阻塞等待
- 退出时必须等待 API 保存完成才能返回
- 如果网络慢，用户会感觉明显卡顿
- 实际上进度已经在切题时保存过了

### 3. 重复保存
- 答题、切题、退出时都会保存
- 造成不必要的 API 调用

## 优化方案

### 方案一：防抖保存（已实施）

**原理**：用户停止操作 800ms 后才保存进度，减少 API 调用频率。

**修改位置**：`pages/Student/PracticeMode.tsx`

**修改内容**：

```typescript
// 原代码：立即保存
useEffect(() => {
  const saveProgress = async () => {
    // ... 保存逻辑
  };
  saveProgress(); // 立即执行
}, [currentIndex, userAnswers, ...]);

// 优化后：防抖保存
useEffect(() => {
  const timeoutId = setTimeout(async () => {
    try {
      // ... 保存逻辑
    } catch (error) {
      console.error('[自动保存] 失败:', error);
    }
  }, 800); // 800ms 防抖延迟
  
  return () => clearTimeout(timeoutId);
}, [currentIndex, userAnswers, ...]);
```

### 方案二：后台异步保存（已实施）

**原理**：退出时不等待保存完成，让保存在后台进行。

**修改内容**：

```typescript
// 原代码：等待保存完成
const handleExit = async () => {
  if (!isMockMode && !isSmartReviewMode && bank && questions.length > 0) {
    try {
      await store.updatePracticeRecord(...); // 阻塞等待
    } catch (error) {
      console.error('保存进度失败:', error);
    }
  }
  onFinish();
};

// 优化后：后台保存
const handleExit = async () => {
  if (!isMockMode && !isSmartReviewMode && bank && questions.length > 0) {
    // 后台保存，不等待完成
    const savePromise = (async () => {
      try {
        await store.updatePracticeRecord(...);
        console.log('[退出保存] 进度保存成功');
      } catch (error) {
        console.error('[退出保存] 进度保存失败:', error);
      }
    })();
    // 不等待，立即退出
  }
  onFinish(); // 立即执行
};
```

### 方案三：移除重复保存（已实施）

**原理**：答题和切题时不再立即保存，依赖防抖机制统一处理。

**修改位置**：
- `handleOptionClick` - 单选题/判断题答题
- `handleConfirmMultiple` - 多选题确认
- `handleNext` - 下一题
- `handleSubmitFillBlank` - 填空题提交
- `handleSubmitShortAnswer` - 简答题提交

**修改内容**：

```typescript
// 原代码：答题后立即保存
const handleOptionClick = async (label: string) => {
  // ... 答题逻辑
  await saveProgressImmediately(currentIndex, newAnswers); // 立即保存
};

// 优化后：只更新引用，依赖防抖保存
const handleOptionClick = async (label: string) => {
  // ... 答题逻辑
  currentProgressRef.current.userAnswers = newAnswers; // 只更新引用
  // 防抖保存会自动处理
};
```

### 方案四：删除冗余代码（已实施）

删除了不再使用的 `saveProgressImmediately` 函数（约 100 行代码）。

## 注意事项

### 1. 数据安全
- 防抖延迟设置为 800ms，平衡了性能和数据安全
- 退出时仍会触发保存，只是不等待完成
- 如果用户在 800ms 内关闭浏览器，可能丢失最后的进度

### 2. 网络异常
- 保存失败会在控制台记录错误日志
- 不会阻止用户继续操作
- 建议后续添加重试机制

### 3. 并发冲突
- 当前未处理多设备同时使用的情况
- 建议后续添加版本号或时间戳机制
