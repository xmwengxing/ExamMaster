# 智能复习中心题库筛选功能

## 功能概述

智能复习中心新增题库筛选功能，允许学员按题库分别查看和复习错题，提供更精准的学习体验。

## 更新时间
2026-02-11

## 功能特性

### 1. 题库选择器
- 显示所有包含错题的题库
- 每个题库按钮显示错题数量
- 支持"全部题库"视图
- 实时统计各题库错题数量

### 2. 智能筛选
- 选择题库后，仅显示该题库的错题
- 统计数据（今日待巩固、已完全掌握、历史错题总计）自动更新
- 题目列表自动过滤
- 分页自动重置

### 3. 视觉反馈
- 当前选中的题库高亮显示
- 显示当前筛选状态提示
- 题目列表标题显示当前题库名称

## 使用方法

### 查看全部错题
1. 进入智能复习中心
2. 默认显示"全部题库"
3. 可以看到所有题库的错题

### 按题库筛选
1. 点击题库选择器中的任意题库按钮
2. 页面自动刷新，仅显示该题库的错题
3. 统计卡片更新为该题库的数据
4. 点击"全部题库"按钮可返回全部视图

### 启动智能复习
1. 选择目标题库（或保持"全部题库"）
2. 点击"启动今日智能复习"按钮
3. 系统将根据当前筛选条件启动复习

## 技术实现

### 前端组件更新
**文件**：`pages/Student/Mistakes.tsx`

**新增状态**：
```typescript
// 题库选择状态（null 表示"全部题库"）
const [selectedBankId, setSelectedBankId] = useState<string | null>(null);
```

**核心逻辑**：
```typescript
// 根据选择的题库过滤错题
const filteredMistakes = useMemo(() => {
  if (!selectedBankId) {
    return mistakes; // 全部题库
  }
  return mistakes.filter(m => m.bankId === selectedBankId);
}, [mistakes, selectedBankId]);

// 按题库统计错题数量
const bankStats = useMemo(() => {
  const stats = new Map<string, number>();
  mistakes.forEach(m => {
    stats.set(m.bankId, (stats.get(m.bankId) || 0) + 1);
  });
  return stats;
}, [mistakes]);
```

## 用户体验优化

### 1. 自动隐藏空题库
- 没有错题的题库不会显示在选择器中
- 避免用户点击后看到空列表

### 2. 分页自动重置
- 切换题库时自动跳转到第一页
- 避免页码超出范围导致空白

### 3. 实时统计更新
- 所有统计数据基于当前筛选条件
- 确保数据准确性

### 4. 视觉一致性
- 选中状态使用品牌色（indigo-600）
- 未选中状态使用灰色
- 按钮显示错题数量徽章

## 应用场景

### 场景 1：专项复习
学员想要集中复习某个科目的错题：
1. 选择对应题库
2. 查看该题库的错题统计
3. 启动智能复习

### 场景 2：全面复习
学员想要复习所有科目的错题：
1. 保持"全部题库"选中
2. 查看总体统计
3. 启动智能复习

### 场景 3：对比分析
学员想要了解各科目的掌握情况：
1. 查看题库选择器中的错题数量
2. 逐个切换题库查看详细统计
3. 针对性地进行复习

## 注意事项

1. **数据一致性**：筛选仅影响前端显示，不影响后端数据
2. **性能优化**：使用 `useMemo` 缓存计算结果，避免重复计算
3. **状态管理**：切换题库时自动重置分页状态
4. **用户反馈**：提供清晰的视觉反馈和状态提示

## 未来优化方向

1. **记忆用户选择**：使用 localStorage 记住用户上次选择的题库
2. **快捷键支持**：支持键盘快捷键切换题库
3. **题库排序**：按错题数量、最近练习时间等排序
4. **批量操作**：支持同时选择多个题库进行复习
5. **数据导出**：支持导出各题库的错题统计报告
