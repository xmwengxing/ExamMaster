# 系统迁移升级指南

## 📋 概述

本指南用于将 EduMaster 项目从 CentOS 7.8 迁移到 Alibaba Cloud Linux 3，并优化部署架构以解决性能问题。

## 🎯 迁移目标

1. **系统升级**: CentOS 7.8 → Alibaba Cloud Linux 3
2. **性能优化**: 解决操作响应慢的问题（5-20秒延迟）
3. **架构优化**: 简化 Nginx 代理层，优化 Docker 配置
4. **兼容性**: 解决 Node.js 和依赖兼容性问题

## 🔍 性能问题分析

### 当前问题
- 讨论管理点击需要 5 秒
- 新增管理员需要 20+ 秒
- AI 解析需要 8 秒显示
- 各种操作普遍响应慢

### 根本原因
1. **CentOS 7.8 系统老旧**: 内核版本低（3.10），Docker 性能差
2. **双层 Nginx 代理**: 宝塔 Nginx → Docker Nginx → API（多余的转发层）
3. **Docker 网络开销**: 容器间通信延迟
4. **资源限制未设置**: 容器可能资源竞争
5. **数据库连接池**: 可能配置不当
6. **Node.js 版本**: 使用替代方案可能性能不佳

## 🚀 系统升级步骤

### 阶段 1: 升级操作系统

1. **登录阿里云控制台**
   - 进入 ECS 实例管理
   - 选择目标服务器

2. **创建系统快照（重要！）**
   - 在升级前创建完整的系统盘快照
   - 快照名称: `centos7-before-upgrade-20260127`

3. **升级到 Alibaba Cloud Linux 3**
   - 选择"更换系统盘"或"原地升级"
   - 系统镜像: Alibaba Cloud Linux 3.2104 LTS 64位
   - 保留数据盘（不要格式化）

4. **升级后首次登录**
   ```bash
   # 检查系统版本
   cat /etc/os-release
   
   # 更新系统
   yum update -y
   
   # 检查内核版本
   uname -r  # 应该是 5.10+ 版本
   ```

### 阶段 2: 安装基础环境

```bash
# 1. 安装 Docker（官方最新版本）
yum install -y yum-utils
yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
yum install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin

# 启动 Docker
systemctl start docker
systemctl enable docker

# 验证安装
docker --version
docker compose version  # 注意是 compose 不是 docker-compose

# 2. 安装 Node.js 20 LTS（官方源）
curl -fsSL https://rpm.nodesource.com/setup_20.x | bash -
yum install -y nodejs

# 验证安装
node --version  # 应该是 v20.x
npm --version

# 3. 配置 Docker 镜像加速（阿里云）
mkdir -p /etc/docker
cat > /etc/docker/daemon.json <<EOF
{
  "registry-mirrors": [
    "https://mirror.ccs.tencentyun.com",
    "https://docker.mirrors.ustc.edu.cn"
  ],
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "10m",
    "max-file": "3"
  }
}
EOF

systemctl daemon-reload
systemctl restart docker
```

### 阶段 3: 恢复网站数据

```bash
# 1. 解压备份
cd /root/backups
tar -xzf system_upgrade_*.tar.gz

# 2. 恢复网站文件
cd system_upgrade_*/sites
for site in */; do
    echo "恢复: ${site}"
    tar -xzf "${site}/files.tar.gz" -C /www/wwwroot/
done

# 3. 恢复 Nginx 配置
cp -r ../nginx/* /www/server/panel/vhost/nginx/

# 4. 恢复 Docker 卷（如果需要）
cd ../docker/volumes
for volume in *.tar.gz; do
    volume_name="${volume%.tar.gz}"
    docker volume create "${volume_name}"
    docker run --rm \
        -v "${volume_name}:/data" \
        -v "$(pwd):/backup" \
        alpine tar -xzf "/backup/${volume}" -C /data
done
```

### 阶段 4: 优化 EduMaster 部署

```bash
cd /www/wwwroot/exammaster.zzzjl.com

# 1. 停止旧服务
docker compose down

# 2. 备份旧配置
cp docker-compose.yml docker-compose.yml.old
cp .env .env.old

# 3. 使用优化配置
cp 服务器脚本/optimized-docker-compose.yml docker-compose.yml
cp 服务器脚本/postgresql-optimized.conf postgres/postgresql.conf

# 4. 创建数据目录
mkdir -p postgres_data
chown -R 999:999 postgres_data  # PostgreSQL 容器用户

# 5. 重新构建并启动（使用新配置）
docker compose build --no-cache
docker compose up -d

# 6. 等待服务启动
sleep 30

# 7. 检查服务状态
docker compose ps
docker compose logs api --tail=50

# 8. 测试健康检查
curl http://localhost:3001/api/health
```

### 阶段 5: 优化宝塔 Nginx 配置

```bash
# 1. 备份现有配置
cp /www/server/panel/vhost/nginx/exammaster.zzzjl.com.conf \
   /www/server/panel/vhost/nginx/exammaster.zzzjl.com.conf.old

# 2. 应用优化配置
cp /www/wwwroot/exammaster.zzzjl.com/服务器脚本/宝塔Nginx优化配置.conf \
   /www/server/panel/vhost/nginx/exammaster.zzzjl.com.conf

# 3. 测试配置
nginx -t

# 4. 重载 Nginx
nginx -s reload

# 或者通过宝塔面板重启 Nginx
```

## 🔧 性能优化要点

### 1. 去除 Docker Nginx 层

**优化前架构:**
```
用户 → 宝塔 Nginx → Docker Nginx → API 容器
```

**优化后架构:**
```
用户 → 宝塔 Nginx → API 容器
```

**好处:**
- 减少一层代理转发
- 降低延迟 30-50%
- 简化配置管理

### 2. Docker 资源限制

```yaml
deploy:
  resources:
    limits:
      cpus: '2.0'
      memory: 1G
    reservations:
      cpus: '0.5'
      memory: 512M
```

### 3. PostgreSQL 性能优化

关键参数（已在 `postgresql-optimized.conf` 中配置）:
- `shared_buffers = 256MB` - 共享内存缓冲区
- `effective_cache_size = 1GB` - 查询规划器缓存
- `work_mem = 16MB` - 每个查询操作内存
- `random_page_cost = 1.1` - SSD 优化

### 4. Nginx 连接优化

```nginx
# 连接优化
proxy_set_header Connection "";
proxy_buffering off;
proxy_request_buffering off;

# 超时优化
proxy_connect_timeout 10s;
proxy_send_timeout 60s;
proxy_read_timeout 60s;
```

### 5. Node.js 性能优化

```bash
# 环境变量
NODE_OPTIONS="--max-old-space-size=512"
UV_THREADPOOL_SIZE="8"
```

## 🛡️ 安全建议

1. **防火墙配置**
   ```bash
   # 只开放必要端口
   firewall-cmd --permanent --add-service=http
   firewall-cmd --permanent --add-service=https
   firewall-cmd --reload
   ```

2. **Docker 安全**
   - 容器使用非 root 用户运行
   - 数据库端口只绑定 localhost
   - 定期更新镜像

3. **定期备份**
   ```bash
   # 添加定时任务
   crontab -e
   # 每天凌晨 2 点备份
   0 2 * * * /www/wwwroot/exammaster.zzzjl.com/服务器脚本/backup-all-sites.sh
   ```
