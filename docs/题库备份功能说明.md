# 题库备份与恢复功能说明

## 功能概述

题库备份功能允许管理员将整个题库（包括题目、图片、标签等所有数据）导出为 SQL 格式的备份文件，并在需要时一键恢复。这对于数据备份、题库迁移、多环境同步等场景非常有用。

## 主要特性

### 1. 完整备份
- ✅ 题库基本信息（名称、分类、等级、描述、分值配置）
- ✅ 所有题目内容（包括富文本、图片等）
- ✅ 题目标签和标签关联
- ✅ 题目排序和章节信息
- ✅ 填空题配置和简答题参考答案

### 2. 灵活导入
- ✅ 支持生成新ID（作为新题库导入）
- ✅ 支持保留原ID（覆盖同名题库）
- ✅ 支持自定义新题库名称
- ✅ 自动验证备份文件格式

### 3. 安全可靠
- ✅ 使用数据库事务确保数据一致性
- ✅ 导入前验证文件格式
- ✅ 自动处理特殊字符和转义
- ✅ 详细的错误提示和日志记录

## 使用方法

### 导出题库备份

1. **进入题库管理页面**
   - 登录管理员账号
   - 进入"题库管理"模块

2. **导出备份**
   - 在题库卡片右上角找到下载图标（<i class="fa-solid fa-download"></i>）
   - 点击下载按钮
   - 系统会自动生成 `.sql` 备份文件并下载
   - 文件名格式：`题库名称_backup_日期.sql`

3. **备份文件内容**
   ```sql
   -- ============================================================
   -- 题库备份文件: 计算机网络基础
   -- 备份时间: 2026-01-28T10:30:00.000Z
   -- 题目数量: 150
   -- 标签数量: 12
   -- ============================================================
   
   BEGIN;
   
   -- 1. 插入题库信息
   INSERT INTO banks (id, name, category, ...) VALUES (...);
   
   -- 2. 插入标签
   INSERT INTO tags (id, name, color, ...) VALUES (...);
   
   -- 3. 插入题目
   INSERT INTO questions (id, bank_id, type, content, ...) VALUES (...);
   
   -- 4. 插入题目-标签关联
   INSERT INTO question_tags (question_id, tag_id, ...) VALUES (...);
   
   COMMIT;
   ```

### 导入题库备份

1. **准备备份文件**
   - 确保有 `.sql` 格式的备份文件
   - 可以是本系统导出的备份，也可以是手动编写的 SQL 文件

2. **导入备份**
   - 在题库管理页面点击"导入备份"按钮
   - 选择 `.sql` 备份文件
   - 系统会自动验证文件格式

3. **选择导入模式**

   **模式一：生成新ID（推荐）**
   - 点击"确定"
   - 输入新题库名称（默认为原名称_副本）
   - 系统会生成全新的ID，作为新题库导入
   - 不会影响现有题库

   **模式二：保留原ID（谨慎使用）**
   - 点击"取消"
   - 系统会保留原始ID
   - 如果存在同ID的题库，会被覆盖
   - 适用于恢复误删除的题库

4. **确认导入**
   - 系统显示导入结果
   - 页面自动刷新，显示新导入的题库

## 使用场景

### 场景1：定期备份
**目的：** 防止数据丢失

**操作：**
1. 每周或每月导出所有题库的备份
2. 将备份文件保存到安全的位置（云盘、移动硬盘等）
3. 建议保留多个版本的备份

**文件命名建议：**
```
计算机网络_backup_2026-01-28.sql
计算机网络_backup_2026-02-04.sql
计算机网络_backup_2026-02-11.sql
```

### 场景2：题库迁移
**目的：** 将题库从一个系统迁移到另一个系统

**操作：**
1. 在源系统导出题库备份
2. 在目标系统导入备份（选择"生成新ID"）
3. 验证题目内容和图片是否正常显示

**注意事项：**
- 图片使用的是富文本中的 base64 或 URL，会一并导出
- 如果图片是外部链接，需要确保目标系统能访问

### 场景3：题库复制
**目的：** 基于现有题库创建新题库

**操作：**
1. 导出原题库备份
2. 导入备份，选择"生成新ID"
3. 输入新题库名称（如：计算机网络_2024版）
4. 在新题库中修改或添加题目

**优势：**
- 快速创建相似题库
- 保留原题库不变
- 适合创建不同难度版本

### 场景4：误删除恢复
**目的：** 恢复误删除的题库

**操作：**
1. 找到最近的备份文件
2. 导入备份，选择"保留原ID"
3. 系统会恢复题库和所有题目

**注意事项：**
- 如果题库ID已被其他题库使用，会覆盖现有数据
- 建议先确认题库ID是否冲突

### 场景5：多环境同步
**目的：** 在开发、测试、生产环境间同步题库

**操作：**
1. 在开发环境完善题库
2. 导出备份
3. 在测试环境导入（生成新ID或保留原ID）
4. 测试通过后，在生产环境导入

**建议：**
- 开发环境使用"生成新ID"，避免ID冲突
- 生产环境使用"保留原ID"，保持数据一致性

## 技术细节

### 备份文件格式

**SQL 标准格式：**
- 使用 PostgreSQL 语法
- 包含完整的 INSERT 语句
- 使用事务确保原子性
- 自动处理特殊字符转义

**字段处理：**
- 字符串：单引号包裹，自动转义
- JSON：转换为 JSONB 格式
- NULL：使用 NULL 关键字
- 布尔值：TRUE/FALSE

**冲突处理：**
```sql
INSERT INTO banks (...) VALUES (...)
ON CONFLICT (id) DO UPDATE SET
  name = EXCLUDED.name,
  category = EXCLUDED.category,
  ...
```

### ID 映射机制

当选择"生成新ID"时，系统会：

1. **提取原始ID**
   - 题库ID
   - 题目ID
   - 标签ID

2. **生成新ID**
   - 使用 UUID v4 生成唯一ID
   - 创建 ID 映射表（旧ID → 新ID）

3. **替换所有引用**
   - 题目中的 bank_id
   - 题目-标签关联中的 question_id 和 tag_id
   - 保持数据关联完整性

### 性能优化

**大题库处理：**
- 使用数据库事务批量插入
- 避免逐条插入，提升性能
- 1000 道题目约需 2-5 秒

**文件大小：**
- 纯文本题目：约 1KB/题
- 包含图片题目：约 10-50KB/题
- 建议单个备份文件不超过 50MB

## 常见问题

### Q1: 备份文件可以手动编辑吗？
**A:** 可以，但需要注意：
- 保持 SQL 语法正确
- 正确转义特殊字符（单引号、反斜杠等）
- 保持 ID 的唯一性和关联性
- 建议使用数据库工具编辑

### Q2: 导入后图片显示不正常？
**A:** 可能的原因：
- 图片使用的是外部链接，目标系统无法访问
- 图片 base64 数据被截断
- 建议使用富文本编辑器重新上传图片

### Q3: 可以跨版本导入备份吗？
**A:** 可以，但需要注意：
- 确保数据库表结构兼容
- 新版本可能有新字段，旧备份会使用默认值
- 建议在测试环境先验证

### Q4: 备份文件可以压缩吗？
**A:** 可以：
- SQL 文件是纯文本，压缩率很高（通常 80-90%）
- 使用 .zip 或 .gz 格式压缩
- 导入前需要先解压

### Q5: 如何批量导出所有题库？
**A:** 目前需要逐个导出，未来版本会支持批量导出。
临时方案：
```bash
# 使用脚本批量导出（需要服务器访问权限）
for bank_id in $(psql -t -c "SELECT id FROM banks"); do
  curl -H "Authorization: Bearer $TOKEN" \
    "http://localhost:3001/api/admin/banks/$bank_id/export" \
    -o "backup_$bank_id.sql"
done
```

### Q6: 导入时提示"题库不存在"？
**A:** 可能的原因：
- SQL 文件格式错误
- 缺少 BEGIN/COMMIT 事务语句
- INSERT 语句语法错误
- 检查文件是否完整

### Q7: 可以导入到不同的数据库吗？
**A:** 理论上可以，但需要注意：
- 目前只支持 PostgreSQL
- 如果目标是 MySQL/SQLite，需要转换 SQL 语法
- JSONB 类型需要转换为 JSON 或 TEXT

## 故障排除

### 导出失败
**症状：** 点击导出按钮无响应或报错

**排查步骤：**
1. 检查浏览器控制台错误信息
2. 确认管理员权限
3. 检查题库是否存在
4. 查看服务器日志

**解决方案：**
```bash
# 查看服务器日志
docker compose logs api | grep "导出"

# 检查数据库连接
docker compose exec postgres psql -U edumaster_user -d edumaster -c "SELECT COUNT(*) FROM banks"
```

### 导入失败
**症状：** 导入时提示错误

**常见错误：**
1. "SQL 文件缺少题库信息" → 文件格式错误
2. "语法错误" → SQL 语句有误
3. "题库不存在" → 事务执行失败

**解决方案：**
1. 使用系统导出的备份文件
2. 检查文件是否完整（有 BEGIN 和 COMMIT）
3. 在数据库工具中测试 SQL 语句

### 图片丢失
**症状：** 导入后题目中的图片不显示

**原因：**
- 图片使用外部链接，链接失效
- 图片 base64 数据被截断

**解决方案：**
1. 重新上传图片
2. 使用富文本编辑器的图片上传功能
3. 确保图片 base64 完整
