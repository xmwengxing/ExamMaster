# 题库批量导入说明

## 问题诊断

### 常见问题

#### 1. 导入后题目只有题干没有选项

**原因**：
- Excel 文件中选项列为空或格式不正确
- 选项没有使用正确的分隔符
- 转换脚本未能正确识别选项列

**解决方案**：
1. 检查 Excel 文件中的选项列是否有数据
2. 确保选项使用以下格式之一：
   - 用 `|` 分隔：`选项A|选项B|选项C|选项D`
   - 用换行分隔（Excel 单元格内换行：Alt + Enter）
   - 用分号分隔：`选项A;选项B;选项C;选项D`
   - 带序号：`A. 选项A  B. 选项B  C. 选项C  D. 选项D`

#### 2. HTML 标签未清理（`<p>` 和 `</p>`）

**原因**：
- 原始文件中包含 HTML 格式的文本
- 转换脚本未清理 HTML 标签

**解决方案**：
- ✅ 已修复：转换脚本现在会自动清理所有 HTML 标签
- ✅ 会清理题干、选项、解析中的 HTML 标签
- ✅ 会清理多余的空白字符和换行符

## 正确的导入流程

### 步骤 1：准备原始文件

将题库文件命名为以下格式之一：
- `原始题库1.xlsx`
- `原始题库2.xlsx`
- `原始题库3.docx`

放在项目根目录。

### 步骤 2：检查 Excel 文件格式

**推荐格式**（5列）：

| 题型 | 题干 | 选项 | 答案 | 解析 |
|------|------|------|------|------|
| 单选 | 下列哪个协议用于加密网页传输？ | HTTP\|FTP\|HTTPS\|SMTP | C | HTTPS是HTTP的安全版本 |
| 判断 | 防火墙主要用于监控和过滤进出网络的数据包。 | | A | 防火墙是网络安全的第一道防线 |
| 多选 | 发现账号被盗应采取哪些措施？ | 立即修改密码\|通知银行\|告知好友\|举报异常 | ABCD | 这些都是减少损失的重要步骤 |

**选项格式要求**：
- ✅ 使用 `|` 分隔：`选项A|选项B|选项C|选项D`
- ✅ 使用换行分隔（Alt + Enter）
- ✅ 使用分号：`选项A;选项B;选项C;选项D`
- ✅ 带序号：`A. 选项A  B. 选项B  C. 选项C`
- ❌ 不要使用逗号分隔（会与 CSV 格式冲突）

### 步骤 3：运行转换脚本

```batch
# Windows
题库转换脚本Python版.bat

# 或直接运行 Python 脚本
python scripts/convert-questions.py

# 指定章节
python scripts/convert-questions.py --chapter "九上第一单元"
```

### 步骤 4：检查生成的 CSV 文件

打开 `转换后的题目-合并.csv`，检查：

1. **选项列是否有数据**：
   ```
   SINGLE,题干内容,选项A|选项B|选项C|选项D,C,解析内容,,
   ```

2. **是否有 HTML 标签**：
   - ✅ 正确：`这是一道题目`
   - ❌ 错误：`<p>这是一道题目</p>`

3. **选项分隔符是否正确**：
   - ✅ 正确：`选项A|选项B|选项C|选项D`
   - ❌ 错误：`选项A,选项B,选项C,选项D`（逗号会导致 CSV 解析错误）

### 步骤 5：导入到系统

1. 登录管理员账号
2. 进入 **题库管理**
3. 选择目标题库
4. 点击 **批量导入**
5. 选择生成的 CSV 文件
6. 等待导入完成

## CSV 文件格式说明

### 标准格式（8个字段）

```csv
题型,题干,选项,答案,解析,单元/章节,填空配置,简答参考答案
SINGLE,题干内容,选项A|选项B|选项C|选项D,C,解析内容,第一章,,
JUDGE,判断题题干,,A,解析内容,第二章,,
MULTIPLE,多选题题干,选项A|选项B|选项C|选项D,ABCD,解析内容,第三章,,
FILL_IN_BLANK,填空题{{blank1}}和{{blank2}},,,,第四章,blank1:答案1|答案2;blank2:答案3,
SHORT_ANSWER,简答题题干,,,,第五章,,参考答案内容
```

### 字段说明

1. **题型**：
   - `SINGLE` - 单选题
   - `MULTIPLE` - 多选题
   - `JUDGE` - 判断题
   - `FILL_IN_BLANK` - 填空题
   - `SHORT_ANSWER` - 简答题

2. **题干**：
   - 题目内容
   - 如包含逗号，需用双引号包裹：`"这是一道题目，包含逗号"`
   - 填空题使用 `{{blank1}}`、`{{blank2}}` 标记空白位置

3. **选项**：
   - 用 `|` 分隔
   - 判断题、填空题、简答题留空
   - 示例：`选项A|选项B|选项C|选项D`

4. **答案**：
   - 单选题：`A`、`B`、`C`、`D` 等
   - 多选题：`ABC`、`ABD` 等（无需分隔）
   - 判断题：`A`（正确）或 `B`（错误）
   - 填空题、简答题：留空

5. **解析**：
   - 选填
   - 如包含逗号，需用双引号包裹

6. **单元/章节**：
   - 选填
   - 用于分类和筛选

7. **填空配置**：
   - 仅填空题需要
   - 格式：`blank1:答案1|答案2;blank2:答案3`
   - 多个空白用分号分隔
   - 每个空白可以有多个正确答案（用 `|` 分隔）

8. **简答参考答案**：
   - 仅简答题需要
   - 用于 AI 评分参考

## 常见错误及解决方案

### 错误 1：选项数量不足

```
第X行：选择题至少需要2个选项
```

**解决方案**：
- 检查选项列是否为空
- 确保使用 `|` 分隔选项
- 至少提供 2 个选项

### 错误 2：答案超出选项范围

```
第X行：答案超出选项范围（最大为D）
```

**解决方案**：
- 检查答案是否正确（如只有 4 个选项，答案不能是 E）
- 检查选项数量是否正确

### 错误 3：字段不足

```
第X行：字段不足（至少需要4个字段）
```

**解决方案**：
- 检查 CSV 文件格式
- 确保每行至少有 4 个字段（题型、题干、选项、答案）
- 检查是否有多余的逗号或引号

### 错误 4：题型无效

```
第X行：题型无效（XXX），应为SINGLE/MULTIPLE/JUDGE/FILL_IN_BLANK/SHORT_ANSWER
```

**解决方案**：
- 检查题型列的值
- 确保使用正确的题型代码
- 转换脚本会自动将"单选"、"多选"、"判断"转换为对应代码
