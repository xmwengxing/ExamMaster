## 架构说明

```
浏览器访问 http://localhost
    ↓
Nginx (80端口) 提供前端页面
    ↓
前端调用 /api 接口
    ↓
Nginx 反向代理到 Express (3001端口)
    ↓
Express 连接 PostgreSQL (5434端口)
```

## 常见问题

### Q: 为什么不能访问 http://localhost:5173？
A: 5173 是 Vite 开发服务器端口，只在本地开发时使用（`npm run dev`）。Docker 环境使用 Nginx 在 80 端口提供服务。

### Q: 登录提示"账号或密码错误"？
A: 请检查：
1. 是否选择了正确的角色（管理平台）
2. 账号是否为 `admin`（不是手机号）
3. 密码是否为 `admin`

### Q: 如何重置管理员密码？
A: 运行以下命令：
```bash
node reset-admin-password.js
```

## 数据库直接操作

如需直接操作数据库：
```bash
# 进入数据库容器
docker exec -it edumaster_postgres psql -U edumaster_user -d edumaster

# 查看管理员账号
SELECT id, phone, role, real_name FROM users WHERE phone = 'admin';

# 退出
\q
```
