## 🐛 常见问题排查

### 问题 1: Service Worker 未注册

**症状**: 控制台显示 "Service Worker 注册失败"

**解决方案**:
1. 确认使用 HTTPS（或 localhost）
2. 检查 `public/sw.js` 文件是否存在
3. 检查 `index.html` 中的注册代码

```javascript
// 手动注册
navigator.serviceWorker.register('/sw.js')
  .then(reg => console.log('注册成功', reg))
  .catch(err => console.error('注册失败', err));
```

### 问题 2: 缓存未生效

**症状**: 刷新页面仍然很慢

**解决方案**:
1. 检查浏览器控制台是否有缓存日志
2. 清除浏览器缓存后重试
3. 检查 localStorage 是否被禁用

```javascript
// 检查缓存
import { getCacheStats } from './utils/cache';
console.log(getCacheStats());

// 手动清除缓存
import { clearAllCache } from './utils/cache';
clearAllCache();
```

### 问题 3: 分页 API 不工作

**症状**: 题目列表返回空数据

**解决方案**:
1. 检查 API 参数是否正确
2. 检查数据库是否有数据
3. 查看服务器日志

```bash
# 测试 API
curl "http://localhost:3001/api/questions?page=1&pageSize=10" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 问题 4: 页面仍然加载慢

**症状**: 优化后仍然需要 5+ 秒

**解决方案**:
1. 检查网络延迟（ping 服务器）
2. 检查数据库性能（慢查询）
3. 检查服务器负载（CPU/内存）
4. 查看浏览器控制台的 Network 标签，找出慢的请求

```bash
# 检查网络延迟
ping exammaster.zzzjl.com

# 检查服务器负载
ssh user@server
top
```
