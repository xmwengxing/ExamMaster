# 性能优化方案 - 启动加速

## 📊 问题分析

### 当前问题
- **现象**: 登录后显示 "正在启动数据库..." 需要 8 秒才能进入页面
- **服务器配置**: 阿里云 2核4G（性能足够）
- **根本原因**: 前端 `refreshAll()` 函数在登录后并行请求 **17个 API 接口**

### 性能瓶颈定位

#### 1. 前端问题（主要）
在 `store.ts` 的 `refreshAll()` 函数中：

```typescript
const promises: Array<Promise<any>> = [
  Promise.resolve(userProfile),
  fetchApi('/banks'),                    // 1. 题库列表
  fetchApi('/questions'),                // 2. 所有题目（可能很大！）
  fetchApi('/exams'),                    // 3. 考试列表
  fetchApi('/config'),                   // 4. 系统配置
  fetchApi('/practice'),                 // 5. 练习记录
  fetchApi('/favorites'),                // 6. 收藏题目
  fetchApi('/user/progress'),            // 7. 用户进度
  // 管理员额外接口
  fetchApi('/admin/students'),           // 8. 学生列表
  fetchApi('/admin/admins'),             // 9. 管理员列表
  fetchApi('/admin/login-logs'),         // 10. 登录日志
  fetchApi('/admin/audit-logs'),         // 11. 审计日志
  fetchApi('/admin/all-progress'),       // 12. 所有进度
  // 其他接口
  fetchApi('/practical/tasks'),          // 13. 实操任务
  fetchApi('/practical/records'),        // 14. 实操记录
  fetchApi('/srs/records'),              // 15. SRS记录
  fetchApi('/mistakes'),                 // 16. 错题本
  fetchApi('/exams/history'),            // 17. 考试历史
];
```

**问题点**:
1. **一次性加载所有题目**: `/questions` 接口可能返回数千道题目
2. **不必要的预加载**: 很多数据在首页不需要（如错题本、考试历史）
3. **串行等待**: 所有接口必须完成才能进入页面
4. **无缓存策略**: 每次刷新都重新加载所有数据

#### 2. 数据库连接问题（次要）
在 `db.js` 中：
```javascript
connectionTimeoutMillis: 2000,   // 连接超时 2秒
```

如果数据库连接慢，会影响所有 API 响应。

## 🎯 优化方案

### 方案 1: 懒加载 + 分阶段加载（推荐）⭐

#### 实施步骤

**阶段 1: 核心数据（立即加载，< 1秒）**
```typescript
// 只加载首页必需的数据
const corePromises = [
  fetchApi('/user/profile'),      // 用户信息
  fetchApi('/banks'),             // 题库列表（小数据）
  fetchApi('/config'),            // 系统配置
];
```

**阶段 2: 次要数据（后台加载，不阻塞页面）**
```typescript
// 页面显示后在后台加载
setTimeout(() => {
  fetchApi('/practice');          // 练习记录
  fetchApi('/favorites');         // 收藏
  fetchApi('/user/progress');     // 进度
}, 100);
```

**阶段 3: 按需加载（访问时才加载）**
```typescript
// 只在用户访问对应页面时加载
- 进入练习页面 → 加载 /questions
- 进入错题本 → 加载 /mistakes
- 进入考试页面 → 加载 /exams 和 /exams/history
- 进入实操页面 → 加载 /practical/tasks 和 /practical/records
```

#### 预期效果
- **首屏加载**: 从 8秒 → **< 1秒**
- **用户体验**: 立即进入首页，数据逐步加载
- **带宽节省**: 减少 70% 的初始请求

### 方案 2: 题目数据分页加载

#### 问题
`/questions` 接口一次性返回所有题目，可能有数千条数据。

#### 优化
```typescript
// 修改 API 支持分页

```

#### 预期效果
- **数据量**: 从几MB → 几十KB
- **加载时间**: 从 3-5秒 → < 0.5秒

### 方案 3: 添加本地缓存

#### 实施
```typescript
// 使用 localStorage 缓存不常变化的数据
const CACHE_KEYS = {
  BANKS: 'edu_cache_banks',
  CONFIG: 'edu_cache_config',
  QUESTIONS: 'edu_cache_questions',
};

const CACHE_DURATION = 30 * 60 * 1000; // 30分钟

// 缓存读取
const getCachedData = (key: string) => {
  const cached = localStorage.getItem(key);
  if (!cached) return null;
  
  const { data, timestamp } = JSON.parse(cached);
  if (Date.now() - timestamp > CACHE_DURATION) {
    localStorage.removeItem(key);
    return null;
  }
  
  return data;
};

// 缓存写入
const setCachedData = (key: string, data: any) => {
  localStorage.setItem(key, JSON.stringify({
    data,
    timestamp: Date.now()
  }));
};
```

#### 预期效果
- **二次访问**: 从 8秒 → **< 0.5秒**
- **离线支持**: 部分数据可离线访问

### 方案 4: 数据库连接池优化

#### 当前配置
```javascript
// db.js
min: 2,                          // 最小连接数
max: 20,                         // 最大连接数
connectionTimeoutMillis: 2000,   // 连接超时 2秒
```

#### 优化建议
```javascript
// 生产环境优化配置
min: 5,                          // 增加最小连接数（预热）
max: 30,                         // 增加最大连接数
connectionTimeoutMillis: 5000,   // 增加超时时间
idleTimeoutMillis: 60000,        // 增加空闲超时（1分钟）

// 添加连接预热
pool.on('connect', async (client) => {
  // 预热连接，执行简单查询
  await client.query('SELECT 1');
});
```

#### 预期效果
- **首次连接**: 从 2秒 → < 0.5秒
- **并发性能**: 提升 50%

## 🚀 实施计划

## 📝 代码实施示例

### 1. 修改 store.ts - 分阶段加载

```typescript
const refreshAll = useCallback(async () => {
  const token = localStorage.getItem('edu_token');
  if (!token) {
    setIsLoading(false);
    return;
  }

  try {
    // ========== 阶段 1: 核心数据（阻塞加载）==========
    const [userProfile, banksData, configData] = await Promise.all([
      fetchApi('/user/profile').catch(() => null),
      fetchApi('/banks').catch(() => []),
      fetchApi('/config').catch(() => null),
    ]);

    if (!userProfile) {
      setIsLoading(false);
      return;
    }

    // 立即更新核心状态，让页面可以显示
    setCurrentUser(userProfile);
    setBanks(banksData || []);
    setSystemConfig(configData);
    setIsLoading(false); // 🔥 关键：立即解除加载状态

    // ========== 阶段 2: 次要数据（后台加载）==========
    setTimeout(async () => {
      const [practiceData, favoritesData, progressData] = await Promise.all([
        fetchApi('/practice').catch(() => []),
        fetchApi('/favorites').catch(() => []),
        fetchApi('/user/progress').catch(() => []),
      ]);

      setPracticeRecords(practiceData || []);
      setFavorites(favoritesData || []);
      // 更新进度数据...
    }, 100);

    // ========== 阶段 3: 管理员数据（后台加载）==========
    if (userProfile.role === 'ADMIN') {
      setTimeout(async () => {
        const [students, admins, logs] = await Promise.all([
          fetchApi('/admin/students').catch(() => []),
          fetchApi('/admin/admins').catch(() => []),
          fetchApi('/admin/login-logs').catch(() => []),
        ]);

        setStudents(students || []);
        setAdmins(admins || []);
        setLoginLogs(logs || []);
      }, 200);
    }

  } catch (err) {
    console.error("Refresh failed", err);
    setIsLoading(false);
  }
}, []);
```

loadQuestions: async (bankId: string) => {
  if (!bankId) return;
  
  try {
    const qs = await fetchApi(`/questions?bankId=${bankId}`);
    setQuestions(prev => {
      // 合并新数据，避免重复
      const existing = prev.filter(q => q.bankId !== bankId);
      return [...existing, ...(qs || [])];
    });
  } catch (err) {
    console.error('Failed to load questions', err);
  }
},

## ⚠️ 注意事项

### 1. 数据一致性
- 后台加载的数据可能不是最新的
- 需要在用户操作时刷新相关数据

### 2. 错误处理
- 后台加载失败不应影响页面显示
- 需要添加重试机制

### 3. 缓存失效
- 数据更新时需要清除缓存
- 避免用户看到过期数据

### 4. 兼容性
- localStorage 有大小限制（5-10MB）
- 需要处理存储满的情况
