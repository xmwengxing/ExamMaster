# 督学管理练习明细功能修复说明

## 问题描述

管理员在督学管理页面点击"练习明细"按钮时出现 403 权限错误：

```
/api/admin/students/…11/practice-stats:1 Failed to load resource: the server responded with a status of 403 (Forbidden)
index-CcziJJDq.js:389 获取练习统计失败
```

## 问题原因

前端代码使用了错误的 localStorage 键名来获取认证 token：

```typescript
// ❌ 错误：使用了 'token' 键名
const token = localStorage.getItem('token');
```

系统统一使用的 token 键名是 `'edu_token'`，而不是 `'token'`。使用错误的键名导致：

1. 获取到的 token 为 `null`
2. 请求头中没有有效的认证信息
3. 后端认证中间件返回 403 Forbidden

## 修复方案

修改 `pages/Admin/Supervisor.tsx` 中的 `fetchPracticeStats` 函数，使用正确的 token 键名：

```typescript
// ✅ 正确：使用 'edu_token' 键名
const token = localStorage.getItem('edu_token');
```

同时增强了错误日志，输出更详细的错误信息：

```typescript
console.error('获取练习统计失败:', response.status, response.statusText);
```

## 修改文件

- `pages/Admin/Supervisor.tsx`：修改 `fetchPracticeStats` 函数中的 token 获取逻辑

## 功能说明

"练习明细"功能用于查看学员近 30 天的练习统计，包括：

1. **统计概览**：
   - 总练习题数
   - 练习天数
   - 日均题数

2. **每日练习明细**：
   - 每天的练习日期
   - 每天完成的题目数量
   - 练习模式分布（顺序练习、记忆模式、错题练习）

3. **可视化展示**：
   - 有练习的日期高亮显示
   - 无练习的日期灰色显示
   - 每日练习数据以卡片形式展示

## 后端接口

- **路由**：`GET /api/admin/students/:userId/practice-stats`
- **权限**：需要管理员权限（`auth` + `adminAuth` 中间件）
- **参数**：`userId` - 学员ID
- **返回**：近 30 天的每日练习统计数组
