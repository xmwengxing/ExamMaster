## 系统概述

EduMaster 是一个全栈刷题系统，包含以下组件：

- **前端**：React 19 + Vite 6
- **后端**：Node.js 18+ + Express 5
- **数据库**：PostgreSQL 14+
- **Web 服务器**：Nginx
- **容器化**：Docker + Docker Compose

### 系统架构

```
[用户浏览器]
     |
     | HTTPS (443)
     v
[Nginx 反向代理]
     |
     +---> [静态文件] (React 构建产物)
     |
     +---> [API 请求] --> [Node.js API 服务器] (3001)
                              |
                              v
                         [PostgreSQL] (5432)
                              |
                              v
                         [数据卷持久化]
```

## 本地开发环境部署

### 步骤 1：安装依赖

```bash
# 安装 Node.js 依赖
npm install
```

### 步骤 2：配置环境变量

```bash
# 复制环境变量模板
cp .env.example .env

# 编辑 .env 文件
# 注意：本地开发使用端口 5434 避免与本地 PostgreSQL 冲突
```

关键配置：
```env
NODE_ENV=development
PORT=3001
DB_HOST=localhost
DB_PORT=5434
DB_NAME=edumaster
DB_USER=edumaster_user
DB_PASSWORD=your_password_here
JWT_SECRET=your_jwt_secret_here
```

### 步骤 3：启动 Docker 服务

```bash
# 启动 PostgreSQL 数据库
docker-compose up -d postgres

# 等待数据库启动（约 10 秒）
docker-compose logs -f postgres
```

### 步骤 4：初始化数据库

数据库会自动通过 `postgres/init.sql` 初始化。如果需要手动初始化：

```bash
docker exec -i edumaster_postgres psql -U edumaster_user -d edumaster < postgres/init.sql
```

```bash
# 开发模式（带热重载）
npm run dev

# 或生产模式
npm start
```

### 步骤 6：启动前端开发服务器

```bash
# 在另一个终端
npm run dev:client
```

### 步骤 7：访问应用

- 前端：http://localhost:5173
- 后端 API：http://localhost:3001
- 健康检查：http://localhost:3001/api/health

生产服务器 (47.104.173.139) 使用**宝塔面板管理 Nginx**，架构与标准 Docker 部署有所不同：

### 环境变量详解

| 变量名 | 说明 | 默认值 | 必填 |
|--------|------|--------|------|
| NODE_ENV | 运行环境 | production | 是 |
| PORT | 后端端口 | 3001 | 是 |
| DB_HOST | 数据库主机 | localhost | 是 |
| DB_PORT | 数据库端口 | 5432 | 是 |
| DB_NAME | 数据库名称 | edumaster | 是 |
| DB_USER | 数据库用户 | edumaster_user | 是 |
| DB_PASSWORD | 数据库密码 | - | 是 |
| JWT_SECRET | JWT 密钥 | - | 是 |
| ALLOWED_ORIGINS | CORS 允许的来源 | - | 是 |
| DEEPSEEK_API_KEY | AI 功能密钥 | - | 否 |

### Docker Compose 配置

#### 服务说明

1. **postgres**：PostgreSQL 数据库
   - 镜像：postgres:14-alpine
   - 端口：5432（内部）
   - 数据持久化：postgres_data 卷

2. **api**：Node.js 后端服务
   - 构建：Dockerfile
   - 端口：3001
   - 依赖：postgres

3. **nginx**：Web 服务器
   - 镜像：nginx:alpine
   - 端口：80, 443
   - 依赖：api

#### 自定义配置

编辑 `docker-compose.yml`：

```yaml
services:
  postgres:
    environment:
      POSTGRES_DB: ${DB_NAME}
      POSTGRES_USER: ${DB_USER}
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    # 暴露端口到主机（仅开发环境）
    ports:
      - "127.0.0.1:5434:5432"
```

### Nginx 配置

关键配置项（`nginx/nginx.conf`）：

```nginx
# SSL 证书路径
ssl_certificate /etc/nginx/ssl/cert.pem;
ssl_certificate_key /etc/nginx/ssl/key.pem;

# API 代理
location /api/ {
    proxy_pass http://api:3001;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}

# 静态文件缓存
location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
    expires 1y;
    add_header Cache-Control "public, immutable";
}
```

## 故障排查

### 常见问题

#### 1. 数据库连接失败

**症状**：
```
error: role "edumaster_user" does not exist
```

**解决方案**：
```bash
# 检查数据库是否启动
docker-compose ps postgres

# 检查数据库日志
docker-compose logs postgres

# 重新创建数据库
docker-compose down -v
docker-compose up -d postgres
```

#### 2. 端口冲突

**症状**：
```
Bind for 0.0.0.0:5432 failed: port is already allocated
```

**解决方案**：
```bash
# 检查端口占用
netstat -ano | findstr :5432

# 修改 docker-compose.yml 中的端口映射
ports:
  - "127.0.0.1:5434:5432"
```

#### 3. Nginx 502 错误

**症状**：访问网站显示 502 Bad Gateway

**解决方案**：
```bash
# 检查 API 服务是否运行
docker-compose ps api

# 检查 API 日志
docker-compose logs api

# 重启 API 服务
docker-compose restart api
```

#### 4. SSL 证书问题

**症状**：浏览器显示证书无效

**解决方案**：
```bash
# 检查证书文件
ls -la nginx/ssl/

# 验证证书
openssl x509 -in nginx/ssl/cert.pem -text -noout

# 重新获取证书
./scripts/get-cert-simple.sh
```

### 日志查看

```bash
# 查看所有服务日志
docker-compose logs -f

# 查看特定服务日志
docker-compose logs -f postgres
docker-compose logs -f api

# 查看应用日志
tail -f logs/app-*.log
```

- 数据库大小
- 活跃连接数
- 慢查询数量
- 缓存命中率

#### 3. 日志监控

```bash
# 实时查看错误日志
tail -f logs/error-*.log

# 统计错误数量
grep "ERROR" logs/app-*.log | wc -l

# 查找特定错误
grep "Database Error" logs/app-*.log
```
