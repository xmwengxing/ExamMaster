# 题库备份功能 - 快速使用指南

## 🎯 功能说明

题库备份功能可以将整个题库（包括所有题目、图片、标签）导出为 SQL 文件，并支持一键恢复。

**适用场景：**
- ✅ 定期备份防止数据丢失
- ✅ 题库迁移到其他系统
- ✅ 复制题库创建新版本
- ✅ 恢复误删除的题库

## 📥 导出备份

### 操作步骤

1. **进入题库管理**
   - 登录管理员账号
   - 点击"题库管理"

2. **导出题库**
   - 在题库卡片右上角找到 <i class="fa-solid fa-download"></i> 下载图标
   - 点击下载按钮
   - 系统自动生成并下载 `.sql` 备份文件

3. **保存备份**
   - 文件名格式：`题库名称_backup_日期.sql`
   - 建议保存到云盘或移动硬盘
   - 保留多个版本的备份

### 示例

```
计算机网络_backup_2026-01-28.sql  (150道题目，包含所有图片和标签)
```

## 📤 导入备份

### 操作步骤

1. **准备备份文件**
   - 确保有 `.sql` 格式的备份文件

2. **导入备份**
   - 在题库管理页面点击"导入备份"按钮
   - 选择 `.sql` 备份文件

3. **选择导入模式**

   **模式一：生成新ID（推荐）**
   - 适用于：复制题库、题库迁移
   - 点击"确定"
   - 输入新题库名称
   - 系统创建全新题库，不影响现有数据

   **模式二：保留原ID（谨慎）**
   - 适用于：恢复误删除的题库
   - 点击"取消"
   - 如果存在同ID题库会被覆盖

4. **确认导入**
   - 系统显示导入结果
   - 页面自动刷新

## 💡 使用建议

### 定期备份
```
✅ 每周备份一次重要题库
✅ 大量修改前先备份
✅ 保留至少 3 个版本
```

### 文件命名
```
题库名称_backup_日期_版本.sql

示例：
计算机网络_backup_2026-01-28_v1.sql
计算机网络_backup_2026-02-04_v2.sql
```

### 存储位置
```
✅ 云盘自动同步（推荐）
✅ 本地保留副本
✅ 重要题库异地备份
```

## ⚠️ 注意事项

1. **备份文件包含完整数据**
   - 题库信息、所有题目、图片、标签
   - 注意保密，不要上传到公开位置

2. **导入前先测试**
   - 建议先在测试环境导入
   - 检查题目数量和内容
   - 验证图片是否正常显示

3. **覆盖操作不可恢复**
   - 使用"保留原ID"模式会覆盖现有数据
   - 操作前务必确认

## 🔧 常见问题

### Q: 备份文件很大怎么办？
**A:** 可以压缩为 .zip 格式，压缩率通常达到 80-90%。导入前先解压。

### Q: 导入后图片不显示？
**A:** 图片已包含在备份中。如果不显示，可能是浏览器缓存问题，按 Ctrl+Shift+R 强制刷新。

### Q: 可以跨系统导入吗？
**A:** 可以，但目标系统必须也是 PostgreSQL 数据库。

### Q: 如何批量导出所有题库？
**A:** 目前需要逐个导出。未来版本会支持批量导出。
