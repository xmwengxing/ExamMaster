# 学员端性能优化方案

## 🔍 问题诊断

### 当前问题
1. **题目数据过大**：8.24MB 的 questions 数据
2. **HTTP/2 协议错误**：`ERR_HTTP2_PROTOCOL_ERROR 200`
3. **缓存失败**：数据超过 5MB 限制，无法缓存
4. **题库显示 0 题**：数据加载失败导致

### 根本原因
前端一次性加载所有题目数据（`/api/questions`），当题目数量多时：
- 响应体过大（8MB+）
- 超过 HTTP/2 单个响应限制
- 无法缓存到 localStorage
- 加载时间长，用户体验差

## 🎯 优化方案

### 方案 1：按需加载题目（推荐）✅

**核心思路**：
- 首页只加载题库元数据（题目数量、名称等）
- 进入练习/考试时才加载具体题目
- 使用分页加载大题库

**优点**：
- 首页加载速度快（< 1秒）
- 内存占用小
- 支持大规模题库（10000+ 题）

**实现步骤**：

#### 1. 修改前端数据加载策略

```typescript
// store.ts - 修改 refreshAll 函数

// ❌ 旧方案：加载所有题目
const questionsData = await fetchApi('/questions');

// ✅ 新方案：只加载题库元数据
const banksWithCount = await fetchApi('/banks?includeCount=true');
```

#### 2. 按需加载题目

```typescript
// 进入练习页面时才加载题目
const loadQuestionsForBank = async (bankId: string) => {
  // 检查缓存
  const cacheKey = `questions_${bankId}`;
  const cached = getCachedData(cacheKey);
  if (cached) return cached;
  
  // 从服务器加载
  const questions = await fetchApi(`/questions?bankId=${bankId}`);
  
  // 缓存单个题库的题目
  setCachedData(cacheKey, questions, 30 * 60 * 1000);
  
  return questions;
};
```

#### 3. 分页加载大题库

```typescript
// 对于超大题库，使用分页
const loadQuestionsPage = async (bankId: string, page: number, pageSize: number = 50) => {
  return await fetchApi(`/questions?bankId=${bankId}&page=${page}&pageSize=${pageSize}`);
};
```

### 方案 2：压缩和优化数据结构

**核心思路**：
- 后端返回精简的数据结构
- 使用 gzip 压缩
- 移除不必要的字段

**实现步骤**：

#### 1. 后端添加精简模式

```javascript
// src/controllers/question.controller.js

export async function getQuestions(req, res, next) {
  const { bankId, slim } = req.query;
  
  // 精简模式：只返回必要字段
  if (slim === 'true') {
    const questions = await questionService.getQuestionsSlim(req.db, { bankId });
    return res.json(questions);
  }
  
  // 完整模式
  const questions = await questionService.getQuestions(req.db, { bankId });
  res.json(questions);
}
```

#### 2. 精简数据结构

```javascript
// src/services/question.service.js

export async function getQuestionsSlim(db, { bankId }) {
  const query = `
    SELECT 
      id, 
      bank_id as "bankId",
      type,
      LEFT(content, 100) as content,  -- 只返回前100字符
      tags,
      chapter
    FROM questions
    ${bankId ? 'WHERE bank_id = $1' : ''}
    ORDER BY created_at DESC
  `;
  
  const result = await db.query(query, bankId ? [bankId] : []);
  return result.rows;
}
```

### 方案 3：增量加载和虚拟滚动

**核心思路**：

```typescript
// store.ts - 添加新函数

const loadBankQuestions = useCallback(async (bankId: string) => {
  try {
    const cacheKey = `questions_bank_${bankId}`;
    
    // 检查缓存
    const cached = getCachedData<Question[]>(cacheKey);
    if (cached) {
      console.log(`[loadBankQuestions] 使用缓存: ${bankId}`);
      setQuestions(cached);
      return cached;
    }
    
    // 从服务器加载
    console.log(`[loadBankQuestions] 加载题库: ${bankId}`);
    const questions = await fetchApi(`/questions?bankId=${bankId}`);
    
    // 缓存单个题库
    setCachedData(cacheKey, questions, 30 * 60 * 1000);
    setQuestions(questions);
    
    return questions;
  } catch (error) {
    console.error('[loadBankQuestions] 加载失败:', error);
    return [];
  }
}, []);
```

## 🔄 HTTP/2 错误修复

### 问题原因
HTTP/2 对单个响应有大小限制（通常 8-16MB），超过会报 `ERR_HTTP2_PROTOCOL_ERROR`。

### 解决方案

#### 1. Nginx 配置优化

```nginx
# nginx/nginx.conf 或 宝塔Nginx配置

http {
    # 增加缓冲区大小
    client_body_buffer_size 10M;
    client_max_body_size 50M;
    
    # HTTP/2 设置
    http2_max_field_size 16k;
    http2_max_header_size 32k;
    
    # 如果问题持续，可以禁用 HTTP/2（临时方案）
    # listen 443 ssl;  # 移除 http2
}
```

#### 2. 后端响应分片

```javascript
// src/controllers/question.controller.js

export async function getQuestions(req, res, next) {
  try {
    const { bankId, page, pageSize = 100 } = req.query;
    
    // 强制分页，避免单次返回过多数据
    const result = await questionService.getQuestionsPaginated(req.db, {
      bankId,
      page: parseInt(page) || 1,
      pageSize: Math.min(parseInt(pageSize), 100) // 最多100条
    });
    
    res.json(result);
  } catch (error) {
    next(error);
  }
}
```
