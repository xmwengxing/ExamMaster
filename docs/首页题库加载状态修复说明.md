# 首页题库加载状态修复说明

## 问题描述

用户反馈：切换题库后，首页的加载状态指示器不显示，且题库未加载完成时，顺序练习和背题模式按钮仍可点击，点击后进入练习页面但没有题目。

## 问题原因

1. **加载状态设置时机不当**：在 `handleSetActiveBank` 函数中，`loadBankQuestions` 是异步调用，但 `setIsLoadingQuestions(true)` 是在 `loadBankQuestions` 函数内部才设置的，导致从切换题库到设置加载状态之间有一个短暂的间隙。

2. **缓存加载无视觉反馈**：从内存缓存加载题目时，由于速度太快（几乎瞬间完成），用户感觉不到任何加载过程，误以为没有反应。

## 修复方案

### 1. 提前设置加载状态

在 `handleSetActiveBank` 函数中，在调用 `loadBankQuestions` 之前就立即设置加载状态：

```typescript
const handleSetActiveBank = useCallback(async (bank: QuestionBank | null) => {
  console.log('[handleSetActiveBank] 切换题库:', bank?.name, bank?.id);
  
  // 先清空当前题目，避免显示旧题库的题目
  setQuestions([]);
  setActiveBank(bank);
  
  // 切换题库时加载该题库的题目
  if (bank && bank.id) {
    // 立即设置加载状态，确保UI能及时响应
    setIsLoadingQuestions(true);
    try {
      await loadBankQuestions(bank.id);
    } catch (error) {
      console.error('[handleSetActiveBank] 加载题目失败:', error);
      // 加载失败时保持题目为空数组
      setQuestions([]);
      // 确保加载状态被清除
      setIsLoadingQuestions(false);
    }
  }
}, [loadBankQuestions]);
```

### 2. 缓存加载添加短暂延迟

在 `loadBankQuestions` 函数中，从内存缓存加载时添加 300ms 延迟，让用户能看到加载状态：

```typescript
// 检查内存缓存（除非强制重新加载）
if (!forceReload) {
  const memoryCache = questionsMemoryCache.get(bankId);
  if (memoryCache) {
    console.log(`[loadBankQuestions] 内存缓存命中: ${bankId} (${memoryCache.data.length} 题)`);
    // 从缓存加载时，添加短暂延迟以显示加载状态（提升用户体验）
    await new Promise(resolve => setTimeout(resolve, 300));
    setQuestions(memoryCache.data);
    setIsLoadingQuestions(false);
    return memoryCache.data;
  }
}
```

## 修改文件

- `store.ts`：修改 `handleSetActiveBank` 和 `loadBankQuestions` 函数

## 效果验证

修复后的效果：

1. ✅ 切换题库时，立即显示加载状态指示器
2. ✅ 加载状态指示器至少显示 300ms，让用户能看到反馈
3. ✅ 加载期间，顺序练习和背题模式按钮被禁用（灰色显示，不可点击）
4. ✅ 加载完成后，按钮恢复可用状态
5. ✅ 加载失败时，正确清除加载状态，避免按钮永久禁用

## 用户体验改进

- **视觉反馈**：用户切换题库时能看到明确的加载动画
- **防误操作**：加载期间按钮被禁用，避免用户点击进入空白练习页面
- **性能优化**：保留内存缓存机制，二次切换同一题库时快速加载
- **错误处理**：加载失败时有明确的错误处理，不会导致UI卡死

## 测试建议

1. 切换不同题库，观察加载状态指示器是否正常显示
2. 快速连续切换题库，验证加载状态是否正确
3. 在加载期间尝试点击顺序练习/背题模式按钮，验证是否被禁用
4. 切换到已加载过的题库（有缓存），验证是否仍显示短暂的加载状态
5. 模拟网络慢速，验证长时间加载时的UI表现
