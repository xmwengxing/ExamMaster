# 题库为空问题修复方案

## 🔍 问题诊断

### 现象
1. 学员端题库显示 0 题
2. 练习页面没有题目
3. 题库卡片显示空白

### 根本原因
在优化性能时，我们移除了 `store.ts` 中的全量题目加载：
```typescript
// ❌ 已移除
const questionsData = await fetchApi('/questions');
```

但多个组件仍然依赖 `store.questions`：
- `Home.tsx` - 计算题目数量
- `Practice.tsx` - 获取章节和题型统计
- `App.tsx` - 练习模式加载题目

## ✅ 修复方案

### 方案 1：使用题库自带的 questionCount（已完成）

**修改文件：** `pages/Student/Home.tsx`

```typescript
// ❌ 旧代码：依赖 store.questions
const currentBankQuestionCount = useMemo(() => {
  if (!activeBank) return 0;
  return store.questions.filter(q => q.bankId === activeBank.id).length;
}, [activeBank, store.questions]);

// ✅ 新代码：使用题库自带的 questionCount
const currentBankQuestionCount = useMemo(() => {
  if (!activeBank) return 0;
  return activeBank.questionCount || 0;
}, [activeBank]);
```

### 方案 2：在进入练习页面时自动加载题目

**修改文件：** `App.tsx`

需要在渲染 `PracticeList` 之前加载题目：

```typescript
case 'practice': {
  // 确保题目已加载
  useEffect(() => {
    if (currentActiveBank?.id && store.questions.length === 0) {
      store.loadBankQuestions(currentActiveBank.id);
    }
  }, [currentActiveBank?.id]);
  
  return <PracticeList

    onAddRecord={store.addPracticeRecord}

  />;
}
```

### 方案 3：修改 handleNavigate 函数

在导航到练习相关页面时自动加载题目：

```typescript
const handleNavigate = useCallback(async (tab: string, params?: any) => {
  // 如果导航到需要题目的页面，先加载题目
  const needsQuestions = ['practice', 'practice-mode', 'favorites', 'mistakes'];
  
  if (needsQuestions.includes(tab)) {
    const bankId = params?.bankId || store.activeBank?.id;
    if (bankId && store.questions.length === 0) {
      await store.loadBankQuestions(bankId);
    }
  }
  
  setActiveTab(tab);
  setActiveParams(params);
}, [store]);
```

## 🚀 快速修复（推荐）

最简单的方法是在 `App.tsx` 中添加一个 effect，当切换到需要题目的页面时自动加载：

```typescript
// 在 App.tsx 的 useEffect 区域添加
useEffect(() => {
  const needsQuestions = ['practice', 'practice-mode', 'favorites', 'mistakes'];
  
  if (needsQuestions.includes(activeTab) && store.activeBank?.id) {
    // 检查是否已加载该题库的题目
    const hasQuestions = store.questions.some(q => q.bankId === store.activeBank?.id);
    
    if (!hasQuestions) {
      console.log('[App] 自动加载题库题目:', store.activeBank.id);
      store.loadBankQuestions(store.activeBank.id);
    }
  }
}, [activeTab, store.activeBank?.id]);
```

## ⚠️ 注意事项

### 缓存问题
如果修改后仍然看不到题目，可能是浏览器缓存问题：

1. **清除 localStorage**
```javascript
// 在浏览器控制台执行
localStorage.clear();
location.reload();
```

2. **清除 Service Worker**
```javascript
// 在浏览器控制台执行
navigator.serviceWorker.getRegistrations().then(registrations => {
  registrations.forEach(r => r.unregister());
});
```

3. **强制刷新**
- Windows: `Ctrl + Shift + R`
- Mac: `Cmd + Shift + R`

### 数据库问题
如果题库确实为空，检查数据库：

```sql
-- 检查题库表
SELECT id, name, question_count FROM banks;

-- 检查题目表
SELECT bank_id, COUNT(*) as count FROM questions GROUP BY bank_id;

-- 更新题库的题目数量
UPDATE banks b
SET question_count = (
  SELECT COUNT(*) FROM questions q WHERE q.bank_id = b.id
);
```
