# 学员首页优化：题库记忆和加载状态指示器

## 更新时间
2026-02-11

## 功能概述

针对学员首页进行两项重要优化，提升用户体验：
1. 记忆学员最后选择的题库
2. 添加题库加载状态指示器

## 优化内容

### 1. 题库选择记忆功能

**问题**：
- 学员每次刷新页面或重新登录后，系统都会跳回默认题库
- 需要重新选择题库，操作繁琐

**解决方案**：
- 使用 `localStorage` 保存学员最后选择的题库 ID
- 页面加载时自动恢复上次选择的题库
- 切换题库时自动保存选择

**技术实现**：
```typescript
// 从 localStorage 恢复上次选择的题库
useEffect(() => {
  const savedBankId = localStorage.getItem('lastSelectedBankId');
  if (savedBankId && banks.length > 0) {
    const savedBank = banks.find(b => b.id === savedBankId);
    if (savedBank && savedBank.id !== activeBank?.id) {
      console.log('[Home] 恢复上次选择的题库:', savedBank.name);
      onBankChange(savedBank);
    }
  }
}, [banks]); // 仅在 banks 加载完成后执行一次

// 保存题库选择到 localStorage
const handleBankChangeWithMemory = (bank: QuestionBank) => {
  localStorage.setItem('lastSelectedBankId', bank.id);
  console.log('[Home] 保存题库选择:', bank.name);
  onBankChange(bank);
};
```

**用户体验**：
- ✅ 刷新页面后自动恢复上次选择的题库
- ✅ 重新登录后自动恢复上次选择的题库
- ✅ 无需重复选择，节省时间

### 2. 题库加载状态指示器

**问题**：
- 首页没有题库加载状态提示
- 用户在题库加载过程中点击"顺序练习"或"背题模式"会导致错误
- 练习页面有加载状态指示器，但首页没有

**解决方案**：
- 在题库选择器下方添加加载状态指示器
- 加载完成后自动消失
- 加载期间禁用"顺序练习"和"背题模式"按钮

**UI 设计**：
```tsx
{/* 题库加载状态指示器 */}
{store.isLoadingQuestions && (
  <div className="bg-gradient-to-r from-indigo-50 to-purple-50 p-4 rounded-2xl border-2 border-indigo-100 shadow-sm animate-in fade-in duration-300">
    <div className="flex items-center gap-3">
      <div className="relative">
        <i className="fa-solid fa-spinner fa-spin text-2xl text-indigo-600"></i>
        <div className="absolute inset-0 bg-indigo-600/10 rounded-full animate-ping"></div>
      </div>
      <div className="flex-1">
        <h3 className="text-sm font-bold text-indigo-900">正在加载题库...</h3>
        <p className="text-xs text-indigo-600 mt-0.5">
          首次加载可能需要5-10秒，请稍候
        </p>
      </div>
    </div>
  </div>
)}
```

**按钮禁用逻辑**：
```typescript
// 判断是否需要禁用（顺序练习和背题模式在加载时禁用）
const isDisabled = store.isLoadingQuestions && (
  a.id === PracticeMode.SEQUENTIAL || 
  a.id === PracticeMode.MEMORY
);

// 按钮样式
className={`... ${
  isDisabled 
    ? 'opacity-50 cursor-not-allowed' 
    : 'hover:shadow-xl hover:border-indigo-100'
}`}

// 点击处理
const handleActionClick = (id: string) => {
  // 如果题库正在加载，禁止点击顺序练习和背题模式
  if (store.isLoadingQuestions && (
    id === PracticeMode.SEQUENTIAL || 
    id === PracticeMode.MEMORY
  )) {
    return; // 静默返回，不执行任何操作
  }
  // ... 其他逻辑
};
```

**用户体验**：
- ✅ 清晰的加载状态提示
- ✅ 防止用户在加载期间误操作
- ✅ 加载完成后自动消失，不影响正常使用
- ✅ 与练习页面的加载状态保持一致

## 技术细节

### localStorage 存储策略

**存储键名**：`lastSelectedBankId`

**存储时机**：
- 用户通过下拉框切换题库时
- 立即保存到 localStorage

**恢复时机**：
- 页面加载完成，题库列表加载完成后
- 仅执行一次（使用 `useEffect` 依赖 `banks`）

**容错处理**：
- 如果保存的题库 ID 不存在（题库被删除），则使用默认题库
- 如果 localStorage 不可用，功能降级为默认行为

### 加载状态管理

**状态来源**：`store.isLoadingQuestions`

**状态更新时机**：
1. 开始加载题库：`setIsLoadingQuestions(true)`
2. 加载完成：`setIsLoadingQuestions(false)`
3. 加载失败：`setIsLoadingQuestions(false)`

**影响范围**：
- 首页的加载状态指示器显示/隐藏
- "顺序练习"按钮的禁用状态
- "背题模式"按钮的禁用状态
- 其他功能按钮不受影响（模拟考试、错题本等）

## 应用场景

### 场景 1：首次登录
1. 学员首次登录系统
2. 选择一个题库进行练习
3. 系统自动保存选择
4. 下次登录时自动恢复该题库

### 场景 2：切换题库
1. 学员在首页切换题库
2. 系统显示加载状态指示器
3. "顺序练习"和"背题模式"按钮变灰禁用
4. 加载完成后，指示器消失，按钮恢复

### 场景 3：刷新页面
1. 学员在练习过程中刷新页面
2. 返回首页后自动恢复上次选择的题库
3. 无需重新选择

### 场景 4：误操作防护
1. 学员切换题库后立即点击"顺序练习"
2. 由于题库正在加载，按钮被禁用
3. 点击无效，防止进入错误状态
4. 加载完成后可正常点击

## 注意事项

1. **localStorage 限制**
   - 存储容量约 5-10MB
   - 仅存储题库 ID，不存储完整数据
   - 数据持久化，除非用户清除

2. **状态同步**
   - 题库选择状态需要与全局状态同步
   - 避免状态不一致导致的问题

3. **用户隐私**
   - localStorage 数据存储在本地
   - 不涉及敏感信息
   - 符合隐私保护要求
