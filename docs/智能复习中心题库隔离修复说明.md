# 智能复习中心题库隔离修复说明

## 问题描述

学员账号的智能复习中心存在以下问题：

1. **"全部题库"视图不完整**：选择"全部题库"时，只显示"今日待巩固"卡片，缺少"已完全掌握"和"历史错题总计"卡片
2. **部分题库功能缺失**：切换到某些题库（如"历史"题库）后，只显示"今日待巩固"卡片，缺少其他卡片和"启动今日智能复习"按钮
3. **统计数据不准确**：切换题库后，统计数据没有正确按题库隔离
4. **按钮显示逻辑错误**："启动今日智能复习"按钮在"全部题库"视图也显示，但应该只在具体题库视图显示

## 问题原因

### 1. 显示逻辑问题

代码中使用了强制显示的内联样式：

```typescript
// ❌ 问题代码：强制显示按钮和卡片
<button style={{ display: 'flex !important', visibility: 'visible !important', opacity: '1 !important' }}>
<div style={{ gridTemplateColumns: 'repeat(3, 1fr)', display: 'grid !important' }}>
```

这导致所有元素都被强制显示，无法根据选择的题库动态控制显示逻辑。

### 2. SRS 记录未按题库过滤

在 `reviewStats` 计算逻辑中，`srsRecords` 包含所有题库的记忆曲线记录，没有按当前选择的题库过滤：

```typescript
// ❌ 问题代码：srsRecords 包含所有题库的数据
const reviewedIds = safeSrsRecords.map(r => r.questionId);
const masteredCount = safeSrsRecords.filter(r => r.status === 'MASTERED').length;
```

在计算 `reviewStats` 时，先过滤 SRS 记录，只保留当前题库的错题对应的记录：

// 使用过滤后的 SRS 记录进行计算
const reviewedIds = filteredSrsRecords.map(r => r.questionId);
const pendingSrs = filteredSrsRecords.filter(r => r.nextReviewDate <= today).map(r => r.questionId);

## 技术细节

### SRS（间隔重复记忆）系统

系统使用艾宾浩斯记忆曲线算法，为每个错题生成复习计划：

1. **首次错误**：立即加入待复习队列
2. **复习成功**：根据难度评级（HARD/GOOD/EASY）计算下次复习时间
3. **多次成功**：逐步延长复习间隔（1天 → 3天 → 7天 → 21天）
4. **完全掌握**：复习间隔超过 21 天，标记为 MASTERED

## 注意事项

1. **数据一致性**：SRS 记录通过 `questionId` 关联，确保删除题目时同步删除 SRS 记录
2. **性能优化**：使用 `useMemo` 缓存计算结果，避免频繁重新计算
3. **用户体验**：切换题库时自动重置分页到第一页，避免显示空白页
4. **响应式设计**：使用 `grid-cols-1 md:grid-cols-3` 确保移动端和桌面端都能正常显示
