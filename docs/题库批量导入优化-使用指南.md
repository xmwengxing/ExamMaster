# 题库批量导入优化 - 使用指南

## 功能概述

本系统提供了三种题库格式转换和导入方式:

1. **Web转换工具** - 在线转换,无需安装
2. **Python GUI工具** - 离线转换,图形界面
3. **命令行工具** - 批量处理,自动化

## 一、Web转换工具使用指南

### 1.1 访问转换工具

1. 登录管理后台: https://exammaster.zzzjl.com
2. 点击左侧菜单"题库管理"
3. 点击"题库转换工具"

### 1.2 上传文件

1. 点击"选择文件"按钮
2. 选择Excel (.xlsx, .xls) 或 Word (.docx) 文件
3. 文件大小限制: 100MB
4. 点击"开始转换"

### 1.3 查看转换结果

转换完成后,系统会显示:
- 总题目数
- 各题型统计 (单选、多选、判断等)
- 题目预览 (前10题)
- 验证错误 (如果有)

### 1.4 下载JSON文件

1. 确认转换结果无误
2. 点击"下载JSON"按钮
3. 保存文件到本地

### 1.5 导入题库

1. 返回题库管理页面
2. 点击"批量导入"
3. 上传刚才下载的JSON文件
4. 等待导入完成

## 二、Python GUI工具使用指南

### 2.1 安装依赖

```bash
# 安装Python依赖
pip install openpyxl python-docx
```

### 2.2 启动工具

```bash
# Windows
python scripts\convert-questions-gui.py

# Linux/Mac
python3 scripts/convert-questions-gui.py
```

### 2.3 使用步骤

1. 点击"选择文件"按钮,选择源文件
2. 点击"选择目录"按钮,选择输出目录
3. (可选) 输入章节名称
4. 选择文件格式 (Excel或Word)
5. 点击"开始转换"
6. 等待转换完成
7. 点击"打开输出文件"查看结果



## 三、文件格式要求

### 3.1 Excel格式

#### 标准格式 (推荐)

| 题型 | 题干 | 选项 | 答案 | 解析 | 单元/章节 | 填空配置 | 简答参考答案 |
|------|------|------|------|------|-----------|----------|--------------|
| SINGLE | 题目内容 | A\|B\|C\|D | A | 解析内容 | 第一章 | | |
| MULTIPLE | 题目内容 | A\|B\|C\|D | A\|B | 解析内容 | 第一章 | | |
| JUDGE | 题目内容 | | A | 解析内容 | 第一章 | | |

#### 题型代码

- `SINGLE` - 单选题
- `MULTIPLE` - 多选题
- `JUDGE` - 判断题
- `FILL_IN_BLANK` - 填空题
- `SHORT_ANSWER` - 简答题

#### 选项格式

- 使用 `|` 分隔选项
- 示例: `选项A|选项B|选项C|选项D`
- 判断题不需要填写选项

#### 答案格式

- 单选题: `A` 或 `B` 或 `C` 或 `D`
- 多选题: `A|B` 或 `A|B|C`
- 判断题: `A` (正确) 或 `B` (错误)

### 3.2 Word格式

#### 标准格式

```
1. 题目内容
A. 选项A
B. 选项B
C. 选项C
D. 选项D
答案: A
解析: 解析内容

2. 题目内容
A. 选项A
B. 选项B
答案: A|B
解析: 解析内容
```

#### 格式要求

- 题目以数字序号开头 (1. 2. 3. ...)
- 选项以字母标记 (A. B. C. D.)
- 答案行以"答案:"或"正确答案:"开头
- 解析行以"解析:"或"答案解析:"开头

## 四、图片题目支持

### 4.1 图片格式

系统支持两种图片存储方式:

1. **Base64编码** (小图片 < 100KB)
   - 图片直接嵌入到题目内容中
   - 适合图标、简单示意图

2. **URL引用** (大图片 ≥ 100KB)
   - 图片上传到服务器,使用URL引用
   - 适合高清图片、复杂图表

### 4.2 在Excel中使用图片

#### 方式1: Base64编码

```html
<img src="data:image/png;base64,iVBORw0KGgoAAAANS..." />
```

#### 方式2: URL引用

```html
<img src="https://cdn.example.com/images/question1.png" />
```

### 4.3 在Word中使用图片

Word文档中的图片会自动提取并转换为Base64或URL格式。

## 五、常见问题

### 5.1 转换失败

**问题**: 上传文件后转换失败

**解决方案**:
1. 检查文件格式是否正确
2. 确认文件大小不超过100MB
3. 检查文件是否损坏
4. 查看错误提示信息

### 5.2 验证错误

**问题**: 转换成功但有验证错误

**解决方案**:
1. 查看错误详情
2. 根据建议修正源文件
3. 重新转换

常见验证错误:
- 题目内容为空
- 选择题选项不足2个
- 答案格式不正确

### 5.3 图片无法显示

**问题**: 导入后图片无法显示

**解决方案**:
1. 检查图片URL是否有效
2. 确认Base64编码完整
3. 检查图片格式是否支持

### 5.4 Python GUI无法启动

**问题**: 运行GUI工具时报错

**解决方案**:
```bash
# 安装依赖
pip install openpyxl python-docx

# 检查tkinter
python -c "import tkinter"

# 如果tkinter缺失:
# Windows: 重新安装Python,勾选tcl/tk
# Ubuntu: sudo apt-get install python3-tk
# CentOS: sudo yum install python3-tkinter
```

## 六、最佳实践

### 6.1 文件准备

1. 使用标准模板
2. 保持格式一致
3. 避免特殊字符
4. 检查数据完整性

### 6.2 批量导入

1. 分批导入 (每批不超过500题)
2. 先测试小批量
3. 验证导入结果
4. 备份原始数据

### 6.3 图片处理

1. 压缩大图片
2. 使用合适的图片格式 (JPG/PNG)
3. 避免过大的图片 (建议 < 1MB)
4. 使用CDN加速
