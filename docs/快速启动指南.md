## 📋 常用命令

### Docker 管理

```bash
# 启动所有服务
docker-compose up -d

# 停止所有服务
docker-compose down

# 重启所有服务
docker-compose restart

# 重启单个服务
docker-compose restart api
docker-compose restart postgres
docker-compose restart nginx

# 查看服务状态
docker-compose ps

# 查看服务日志
docker-compose logs -f
docker-compose logs -f api
docker-compose logs -f postgres

# 进入容器
docker-compose exec api sh
docker-compose exec postgres psql -U edumaster_user -d edumaster

# 重新构建镜像
docker-compose build
docker-compose up -d --build
```

### 数据库管理

```bash
# 连接数据库
docker-compose exec postgres psql -U edumaster_user -d edumaster

# 备份数据库
./scripts/backup.sh

# 恢复数据库
./scripts/restore.sh backups/edumaster_backup_20260123.sql.gz

# 查看数据库大小
docker-compose exec postgres psql -U edumaster_user -d edumaster -c "SELECT pg_size_pretty(pg_database_size('edumaster'));"

# 查看表大小
docker-compose exec postgres psql -U edumaster_user -d edumaster -c "SELECT table_name, pg_size_pretty(pg_total_relation_size(quote_ident(table_name))) FROM information_schema.tables WHERE table_schema = 'public' ORDER BY pg_total_relation_size(quote_ident(table_name)) DESC;"
```

### 日志管理

```bash
# 查看应用日志
tail -f logs/app-$(date +%Y-%m-%d).log

# 查看错误日志
tail -f logs/error-$(date +%Y-%m-%d).log

# 查看 Nginx 日志
docker-compose logs -f nginx

# 清理旧日志（保留最近7天）
find logs/ -name "*.log" -mtime +7 -delete
```

### 性能监控

```bash
# 分析查询性能
node scripts/analyze-query-performance.js

# 监控数据库
./scripts/monitor-database.sh

# 查看连接池状态
docker-compose exec api node -e "const pool = require('./db.js').default; console.log('Total:', pool.totalCount, 'Idle:', pool.idleCount, 'Waiting:', pool.waitingCount);"
```

## 🔧 故障排查

### 问题 1: 服务无法启动

```bash
# 检查容器状态
docker-compose ps

# 查看错误日志
docker-compose logs

# 检查端口占用
netstat -tulpn | grep -E '80|443|3001|5432'

# 重启服务
docker-compose restart
```

### 问题 2: 数据库连接失败

```bash
# 检查 PostgreSQL 容器
docker-compose logs postgres

# 检查环境变量
cat .env

# 测试数据库连接
docker-compose exec postgres psql -U edumaster_user -d edumaster -c "SELECT 1;"

# 重启数据库
docker-compose restart postgres
```

### 问题 3: API 返回 500 错误

```bash
# 查看 API 日志
docker-compose logs -f api

# 查看应用日志
tail -f logs/error-$(date +%Y-%m-%d).log

# 重启 API 服务
docker-compose restart api
```

### 问题 4: 前端无法访问

```bash
# 检查 Nginx 配置
docker-compose exec nginx nginx -t

# 查看 Nginx 日志
docker-compose logs -f nginx

# 检查前端文件
ls -la frontend/dist/

# 重启 Nginx
docker-compose restart nginx
```

### 问题 5: 磁盘空间不足

```bash
# 查看磁盘使用
df -h

# 清理 Docker 镜像
docker system prune -a

# 清理旧日志
find logs/ -name "*.log" -mtime +7 -delete

# 清理旧备份
find backups/ -name "*.sql.gz" -mtime +7 -delete
```

## 🔄 部署更新

### 更新流程

```bash
# 1. 拉取最新代码
git pull origin main

# 2. 备份数据库
./scripts/backup.sh

# 3. 停止服务
docker-compose down

# 4. 重新构建
docker-compose build

# 5. 启动服务
docker-compose up -d

# 6. 验证服务
docker-compose ps
curl http://localhost:3001/api/health

# 7. 查看日志
docker-compose logs -f
```

### 回滚流程

```bash
# 1. 停止服务
docker-compose down

# 2. 回滚代码
git reset --hard <commit-hash>

# 3. 恢复数据库（如需要）
./scripts/restore.sh backups/edumaster_backup_YYYYMMDD.sql.gz

# 4. 重新构建
docker-compose build

# 5. 启动服务
docker-compose up -d
```
