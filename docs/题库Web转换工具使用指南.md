# 题库Web转换工具使用指南

## 概述

题库Web转换工具是一个集成在管理后台的在线格式转换服务，支持将 Excel 和 Word 格式的题库文件转换为系统标准的 JSON 格式。

## 功能特性

### 1. 文件上传
- ✅ 支持拖拽上传和点击上传
- ✅ 支持 Excel (.xlsx, .xls) 和 Word (.docx) 格式
- ✅ 文件大小限制：100MB
- ✅ 实时显示文件信息（名称、大小、类型）

### 2. 文件解析和转换
- ✅ 自动识别文件格式
- ✅ 实时显示解析进度
- ✅ 显示转换阶段（上传→解析→验证→完成）
- ✅ 支持进度条可视化

### 3. 转换结果预览
- ✅ 统计各类题型数量（单选、多选、判断）
- ✅ 预览前10道题目
- ✅ 显示题目内容、选项和答案

### 4. 文件下载
- ✅ 下载为 JSON 格式（系统标准格式）
- ✅ 下载为 CSV 格式（便于编辑）
- ✅ 自动生成文件名（原文件名_日期）

### 5. 错误提示
- ✅ 详细的验证错误列表
- ✅ 错误统计（必填字段、选项、答案格式）
- ✅ 针对性的修正建议
- ✅ 常见错误说明

## 使用步骤

### 步骤1：选择文件

1. 访问管理后台的"题库转换工具"页面
2. 点击上传区域或拖拽文件到上传区域
3. 选择 Excel 或 Word 格式的题库文件
4. 系统会自动验证文件类型和大小

### 步骤2：开始转换

1. 确认文件信息无误后，点击"开始转换"按钮
2. 系统会显示实时进度：
   - 准备上传... (0-10%)
   - 上传文件中... (10-60%)
   - 解析文件中... (60-90%)
   - 验证数据中... (90-100%)
   - 转换完成！

### 步骤3：查看结果

转换完成后，系统会显示：
- 总题目数统计
- 各类题型数量（单选、多选、判断）
- 前10道题目预览
- 验证错误（如果有）

### 步骤4：下载文件

1. 点击"下载 JSON"按钮，下载系统标准格式
2. 或点击"下载 CSV"按钮，下载可编辑格式
3. 文件名格式：`原文件名_日期.json` 或 `原文件名_日期.csv`

## 文件格式要求

### Excel 格式

**表头要求：**
- 第一行必须包含表头
- 必需列：题型、题干、选项、答案
- 可选列：解析、章节

**示例：**

| 题型 | 题干 | 选项 | 答案 | 解析 | 章节 |
|------|------|------|------|------|------|
| SINGLE | 下列哪个协议用于加密网页传输？ | HTTP\|FTP\|HTTPS\|SMTP | C | HTTPS是HTTP的安全版本 | 第一章 |
| MULTIPLE | 发现账号被盗应采取哪些措施？ | 立即修改密码\|通知银行\|告知好友\|举报异常 | ABCD | 这些都是减少损失的重要步骤 | 第二章 |
| JUDGE | 防火墙主要用于监控和过滤进出网络的数据包。 | | A | 防火墙是网络安全的第一道防线 | 网络基础 |

**注意事项：**
- 选项使用竖线 `|` 分隔
- 单选题答案为单个字母（A/B/C/D）
- 多选题答案为多个字母（ABC/ABD）
- 判断题答案为 A（正确）或 B（错误）
- 判断题选项可留空，系统会自动添加"正确"和"错误"选项

### Word 格式

**格式要求：**
- 题目按序号排列
- 选项使用 A、B、C、D 标记
- 答案单独标注

**示例：**
```
1. 下列哪个协议用于加密网页传输？
A. HTTP
B. FTP
C. HTTPS
D. SMTP
答案：C
解析：HTTPS是HTTP的安全版本

2. 防火墙主要用于监控和过滤进出网络的数据包。（判断题）
答案：正确
解析：防火墙是网络安全的第一道防线
```

## 错误处理

### 常见错误及解决方法

#### 1. 题目内容不能为空
**错误信息：** 题目 X - content: 题目内容不能为空

**解决方法：** 确保每道题目都有完整的题干内容

#### 2. 选择题至少需要2个选项
**错误信息：** 题目 X - options: 选择题至少需要2个选项

**解决方法：** 单选题和多选题必须提供至少2个选项，用竖线(|)分隔

#### 3. 答案格式错误
**错误信息：** 题目 X - answer: 答案格式错误

**解决方法：**
- 单选题答案为单个字母（A/B/C/D）
- 多选题答案为多个字母（ABC/ABD）
- 判断题答案为 A（正确）或 B（错误）

#### 4. 答案超出选项范围
**错误信息：** 题目 X - answer: 答案超出选项范围

**解决方法：** 答案必须在提供的选项范围内，如有4个选项，答案只能是A-D

### 错误修正流程

1. 查看错误列表，了解具体错误信息
2. 根据修正建议调整源文件
3. 或下载 CSV 格式，在 Excel 中修正
4. 重新上传修正后的文件

## 技术实现

### 前端技术栈
- React 18 + TypeScript
- Ant Design 5（UI组件库）
- Axios（HTTP客户端）

### 核心功能
1. **文件上传组件**：使用 Ant Design 的 Dragger 组件
2. **进度显示**：使用 Progress 组件显示实时进度
3. **数据展示**：使用 Card、List、Statistic 等组件
4. **错误提示**：使用 Alert、Tag 等组件

### API 接口
- `POST /api/convert/upload`：上传并转换文件
- 请求格式：`multipart/form-data`
- 响应格式：JSON

## 最佳实践

1. **文件准备**
   - 使用模板文件作为起点
   - 确保数据格式规范
   - 避免特殊字符和格式

2. **批量转换**
   - 建议每次转换不超过1000题
   - 大文件可拆分为多个小文件
   - 分批上传和验证

3. **数据验证**
   - 转换前在 Excel 中预检查
   - 转换后仔细查看预览
   - 发现错误及时修正

4. **文件管理**
   - 保留原始文件备份
   - 使用有意义的文件名
   - 记录转换日期和版本

## 故障排查

### 上传失败
- 检查文件大小是否超过100MB
- 检查文件格式是否正确
- 检查网络连接是否正常

### 转换失败
- 检查文件内容是否符合格式要求
- 查看错误提示信息
- 尝试使用模板文件测试

### 下载失败
- 检查浏览器下载设置
- 尝试更换浏览器
- 清除浏览器缓存
