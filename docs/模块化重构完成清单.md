## 🔧 使用指南

### 本地开发

```bash
# 启动开发服务器
npm run dev:server

# 运行测试
npm test

# 构建前端
npm run build

# 验证架构
./验证架构.bat  # Windows
# 或
bash scripts/validate-architecture.sh  # Linux/Mac
```

### Git 同步

```bash
# 方式 1：快速同步（推荐）
双击 "快速同步.bat"

# 方式 2：PowerShell 版本
双击 "运行GitHub同步.bat"

# 方式 3：手动
git add -A
git commit -m "提交信息"
git push origin refactor/modularization
```

### Docker 部署

```bash
# 构建镜像
docker compose build

# 启动服务
docker compose up -d

# 查看日志
docker compose logs -f api

# 重启服务
docker compose restart
```

### CI/CD 验证

```bash
# 推送代码后自动触发
git push origin refactor/modularization

# 查看 GitHub Actions
# https://github.com/xmwengxing/EduMaster_postgresql/actions
```
